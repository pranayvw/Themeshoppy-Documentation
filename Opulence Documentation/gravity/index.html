Theme documentation · v3.2

Everything you need to run Gravity.

Gravity is a stylish Shopify theme built for fashion and appliance stores — quick view, an advanced mega menu, a promotional countdown, a newsletter popup, and a free shipping bar, tuned for a smooth, premium shopping experience on every device.

Start with installation Try the theme Talk to support

First steps

Get up and running in three moves

New to Gravity? This is the shortest path from a blank store to a live, styled theme.

01

Install the theme

Upload the theme package to your Shopify admin and publish it to your store, or install a preset directly from the Shopify Theme Store.

Installation guide
02

Choose your preset

Gravity ships with five presets — Gravity, Decor, Gold, Everbloom, and Mario — each tuned for a different kind of store.

Browse presets
03

Build your homepage

Assemble sections in the theme editor — hero slideshow, featured collections, testimonials — and set your header and footer.
