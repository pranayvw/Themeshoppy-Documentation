FAQ

The FAQ section allows you to display frequently asked questions in an accordion format. It helps customers quickly find answers and improves trust and usability in your store.

Configure the FAQ Try the theme

FAQ Section Settings

  • Color Scheme – Choose section color style.
  • Section Width – Set layout width (Container Width).
  • Border Radius – Adjust rounded corners (e.g., 20).
  • Image – Upload supporting image.
  • Image Position – Left or Right alignment.
  • Text Alignment – Left, Center, or Right alignment.
  • Icon Colors – Customize default and active states.
  • Spacing – Desktop and mobile padding controls.

FAQ Blocks

This section contains 2 blocks:


Heading Block

  • Heading – Add section title (e.g., Frequently Asked Questions).
  • Font Size – Choose heading size (H1 to H5).
  • Color – Set heading text color.

FAQ Item Block

  • Heading – Enter FAQ question (e.g., Are your toys safe for children?)
  • Content – Add short answer for the question.
  • Default Open – Enable to keep the FAQ expanded by default.
Steps
  • Open Theme Customizer in Shopify admin.
  • Go to the FAQ section.
  • Edit the Heading Block and set title, font size, and color.
  • Add FAQ items using the FAQ Item Block.
  • Enter question and short answer.
  • Enable Default Open if required.
  • Click Save to apply changes.
