Video Background

The Video Background section in the Soft theme allows you to showcase engaging video content as a prominent visual element on your store. It is designed to capture visitors' attention instantly and create an immersive browsing experience by combining motion visuals with promotional or brand-focused content.

The section also provides options to customize the heading, text content, text position, colors, font size, and call-to-action button. Additionally, a scroll-based zoom effect can be enabled, causing the video to gradually enlarge as visitors scroll through the page. Once the zoom animation is completed, the following content sections smoothly appear, creating an engaging and immersive browsing experience.

Setup guide

Steps to Set Up the Video Background Section in Your Shopify Theme, Soft

Video Background Settings

The Video Background section provides several customization options to control the media display, text content, and layout positioning.

Settings
  • Color Scheme – Choose the color scheme for the banner section to match your store's branding and overall design.
  • Section Width – Select the layout width of the banner, such as full width, to control how the section appears on the page.
  • Select Video – Upload or select a video to display as the main banner media.
  • Fallback Image – Choose a fallback image to display on devices that do not support video playback.
  • Video for Mobile – Upload a separate video file optimized specifically for mobile devices.
  • Mobile Fallback Image – Choose a fallback image for mobile devices.
  • Banner Height – Adjust the height of the banner to control how much screen space it occupies (e.g., 600px).
  • Banner Overlay – Enable a semi-transparent overlay on the banner to improve text readability over the video or image.
  • Overlay Color – Select the color for the overlay effect.
  • Overlay Opacity – Adjust the transparency level of the overlay (e.g., 30%).
  • Enable Parallax – Enable a parallax effect where the background moves at a different speed than the foreground content as visitors scroll.
  • Enable Zoom Effect – Activate a scroll-based zoom effect where the banner gradually enlarges as visitors scroll down the page.
  • Font Color – Choose the color of the text displayed on the banner.
  • Heading Font Size – Select the size for the heading text.
  • Subheading Font Size – Select the size for the subheading text.
  • Description Font Size – Select the size for the description text.
  • Top Spacing – Set the top padding of the section.
  • Bottom Spacing – Set the bottom padding of the section.

Bar Block Settings

The Bar Block helps you add and manage decorative background strips within the section. These strips can be used to enhance the visual appearance of your store, create separation between content areas, and maintain a consistent design throughout the page.

Settings
  • Bar Color – Select the color of the decorative bar element displayed in the banner section.

How to Set Up the Video Background Section

Steps
  • Open the Theme Customizer.
  • Navigate to the Video Background section on the homepage.
  • Upload a banner image or video for desktop and mobile devices.
  • Adjust the media height, overlay, and banner width settings.
  • Adjust the content position and alignment for both desktop and mobile.
  • Click Save to apply the changes.
