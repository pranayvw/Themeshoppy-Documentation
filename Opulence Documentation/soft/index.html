Theme documentation · v3.2

Everything you need to run Soft.

Soft is a premium Shopify theme designed for brands that want a playful, stylish, and engaging storefront. With a soft, vibrant aesthetic and powerful features like Quick View, Mega Menu, Countdown Section, Newsletter Popup, and Free Shipping Bar, Soft makes it easy to showcase products beautifully and create a smooth, enjoyable shopping experience across all devices.

First steps

Get up and running in three moves

New to Soft? This is the shortest path from a blank store to a live, styled theme.

01

Install the theme

Upload the theme package to your Shopify admin and publish it to your store, or install a preset directly from the Shopify Theme Store.

Installation guide
02

Choose your preset

Soft comes with five presets — Soft, Merit, Graceful, Twinkle, and Pearl — each tuned for a different kind of store.

Browse presets
03

Build your homepage

Assemble sections in the theme editor — Hover cards, Featured collections, Testimonials — and set your header and footer.
