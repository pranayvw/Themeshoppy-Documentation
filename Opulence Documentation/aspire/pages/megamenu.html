Mega menu

The Mega Menu in the Aspire theme allows you to display multiple categories, collections, and promotional images in a wide dropdown layout. This helps customers easily navigate through your store and enhances the overall shopping experience.

Steps to Set Up the Mega Menu in Your Shopify Theme, Aspire

How to Configure the Mega Menu

Steps

  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Aspire theme.
  • In the Header section, click Add block and select Mega menu.
  • Adjust the settings according to your preferences.
  • Click Save to apply your changes.
Follow these steps to configure your Mega Menu
  • Color scheme: Choose a color scheme for the mega menu block. Click Edit scheme to customize or select an existing theme color set.
  • Navigation Menu Item Title / Handle: Enter the navigation menu item title where this mega menu should appear (for example, the parent link 'shop'). Use lowercase letters and hyphens (-) for spaces.
  • Promotion images: Add one or two promotion images to display on the right side of the mega menu.
    • Image: Select or upload a promotional image (for example, Rectangle_45375.jpg).
    • Image caption: Enter a text caption for the promotion image (for example, STATEMENT RINGS, BOLD RINGS).
    • Image link: Set a link destination URL for the promotion image (for example, Rings, Fine Jewellery collection page).

How to Create a Navigation Menu for Mega Menu

Before using the Mega Menu in the theme, you need to create a nested navigation menu in your Shopify admin.

Steps

  • Go to Shopify Admin > Online Store > Navigation.
  • Open the Main Menu.
  • Click Add menu item and create a top-level parent item (for example, Shop).
  • Add sub-menu items like Rings, Necklaces, Earrings, Fine Watches, etc.
  • Drag sub-items slightly to the right under the parent item to create a dropdown structure.
  • Click Save menu.

FAQs

Why is my Mega Menu not showing?

Make sure the Menu Item Title / Handle matches exactly with your parent item in Shopify Navigation (e.g., 'shop'). Also ensure that sub-menu items are properly nested under the parent item.

Where do the mega menu links come from?

All menu items and links are managed in Shopify Admin → Navigation. The theme editor controls the layout, promotion images, captions, and color scheme.
