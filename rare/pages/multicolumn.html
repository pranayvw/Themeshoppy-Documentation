Multicolumns

The Multicolumns section is an essential layout tool designed to highlight key brand pillars, store assurances, unique selling propositions (USPs), guarantees, or feature highlights (such as Curated Just For You, Premium Quality, Secure & Trusted, and Gift Packaging). With flexible column controls, image/icon pickers, and rich text options, it strengthens brand trust across all screen sizes.

Multicolumns Section Settings

Configure section-wide styling including color scheme, heading alignment and typography scale, number of columns per row on desktop and mobile, image size and aspect ratio, content alignment, and desktop/mobile padding.

Steps

  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the template sidebar, select Multicolumns (or click Add section → Multicolumns).
  • Choose a Color scheme and configure Heading alignment and Heading font size.
  • Set the Number of columns per row (e.g., 4 columns), Image size, Aspect ratio, and Content alignment.
  • Select your desired Mobile layout (One column or Two columns).
  • Click + Add Multicolumn in the sidebar to add individual column blocks.
  • For each block, upload an icon or photo under Select image, enter a Heading, enter supporting Text, and optionally set a Heading link.
  • Adjust Desktop padding and Mobile padding sliders and click Save.
  • Color scheme: Select a predefined theme color palette (e.g., Scheme 1, Scheme 2, etc.) to set background and typography color styling for the section. Click Edit scheme to customize colors directly.
  • Heading alignment: Select the alignment for the optional section title (Left, Center, or Right).
  • Heading font size: Choose the typography scale for the section title (e.g., H1, H2, H3, H4, H5, H6).
  • Number of columns per row: Set how many columns appear horizontally across desktop screens using the slider (from 1 to 6, e.g., 4 columns).
  • Block heading font size: Select the typography scale for individual column headers (e.g., H4, H5, or H6).
  • Image size: Select the display size format for icons and photos (e.g., Small, Medium, or Large).
  • Aspect ratio: Choose the image container aspect ratio (e.g., Square, Portrait, or Adapt to image).
  • Content alignment: Select the text and icon alignment within each column (Left, Center, or Right).
  • Mobile layout:
    • Number of columns: Select whether columns stack into One column or a compact Two columns grid on mobile screens.
  • Desktop padding:
    • Padding top: Adjust the top vertical spacing on desktop screens (in pixels, e.g., 40 px).
    • Padding bottom: Adjust the bottom vertical spacing on desktop screens (in pixels, e.g., 40 px).
  • Mobile padding:
    • Padding top: Adjust the top vertical spacing on mobile screens (in pixels, e.g., 40 px).
    • Padding bottom: Adjust the bottom vertical spacing on mobile screens (in pixels, e.g., 40 px).

Multicolumn Block Settings

  • Multicolumn: Each block represents an individual column containing an icon/image, a heading, supporting description copy, and an optional link.
    • Select image: Upload or select an SVG line icon, badge graphic, or photo (e.g., fi_636600.svg).
    • Heading: Enter the title for this column (for example: CURATED JUST FOR YOU). Supports dynamic source connections.
    • Text: Enter the supporting descriptive narrative (for example: Handpicked pieces thoughtfully curated to perfectly match your style). Supports rich text formatting (font size scale, bold, italic, links, and lists) and dynamic source connections.
    • Heading link: Paste or search for a URL, product, collection, or policy page to make the column clickable.

FAQs

Where can I find and add the Multicolumns section?

From your Shopify admin, go to Online Store > Themes and click Customize. In the template sidebar, locate Multicolumns or click Add section > Multicolumns to insert it on your homepage, product page, or about page.

Can I use SVG icons as well as photos for each column?

Yes. The Select image picker accepts both raster images (PNG, JPG, WebP) and scalable vector SVG icons, allowing you to create sharp trust badges and icon value bars.

How do I control the number of columns shown on mobile devices?

Under the Mobile layout settings in the section options, you can choose between One column (full-width stacked cards) or Two columns (compact side-by-side grid) to best suit your content.

Can I add clickable links to my columns?

Yes. Each Multicolumn block includes a Heading link setting. You can link shoppers directly to specific collections, policy pages (like Shipping or Returns), or external websites.
