Build perfect set

The Build perfect set section provides an interactive bundle and set-builder shopping experience. Shoppers can mix and match complementary jewellery pieces or accessories (such as earrings, bracelets, bangles, and necklaces) to construct their own customized set, preview slot selections in real time, view total combined pricing, and add all items to their cart with a single click.

Build perfect set Section Settings

Configure section-wide settings such as the color scheme, main content headings, product catalog pool, bundle slot count, interactive summary tray styling, responsive slider grid settings, product card features, and desktop/mobile padding.

Steps

  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the Template sidebar, select Build perfect set (or click Add section → Build perfect set).
  • Choose a Color scheme for the section background and typography.
  • Under Content, configure the Heading, Font size, and narrative Description.
  • Under Products, select up to 10 products from your store and define the number of Set slots (e.g., 4 items per bundle).
  • Under Your set, customize the summary tray title, description text, buy button label, and secure checkout note.
  • Under Layout, toggle Enable slider and set products per view for large desktop and mobile screens.
  • Adjust Padding (Desktop) and Mobile padding for optimal section spacing.
  • Click Save to publish your set builder.
  • Color scheme: Select a predefined theme color scheme (e.g., Scheme 1, Scheme 2, etc.) to set the background and typography colors for the section. Click Edit scheme to customize scheme colors directly.
  • Content:
    • Heading: Enter the main section headline displayed above the products (for example: BUILD PERFECT SET). Supports dynamic source connections.
    • Font size: Select the heading scale level (e.g., H1, H2, H3, H4, H5, H6) to control typography hierarchy.
    • Description: Enter supporting narrative copy explaining the set builder benefits (for example: Select complementary pieces that effortlessly work together, making it easy to create a beautifully balanced jewellery collection that feels uniquely yours.). Supports rich text formatting (bold, italic, and links).
  • Products:
    • Products: Select up to 10 complementary products from your store catalog to include in the set builder pool.
    • Set slots: Set the maximum number of product slots a customer can add to complete a single bundle (for example: 4).
  • Your set (Bundle Summary Tray):
    • Summary title: Enter the headline for the bundle summary tray displayed at the bottom of the section (for example: YOUR SET).
    • Summary text: Enter supporting guidance text for the summary tray (for example: Build your perfect jewellery set with thoughtfully paired pieces designed.).
    • Buy button label: Enter the text for the bundle purchase button (for example: ADD TO CART).
    • Show secure checkout note: Toggle on to display a trust icon and secure checkout message beneath the purchase button.
    • Secure checkout text: Enter the security assurance text displayed alongside the lock icon (for example: Secure Checkout).
  • Layout:
    • Enable slider: Toggle on to display products in a swipeable horizontal carousel instead of a static multi-row grid.
    • Products per view on large desktop: Set the number of visible product cards displayed simultaneously on large desktop viewports (for example: 6).
    • Products per view on mobile: Choose between 1 product or 2 products per view on mobile screens.
    • Image ratio: Choose the aspect ratio for product thumbnail imagery (e.g., Square, Portrait, Landscape, Adapt to image).
    • Show vendor: Toggle to display the brand/vendor name above each product title.
    • Show secondary image on hover: Toggle on to reveal the second product media image when a shopper hovers over any card.
  • Padding:
    • Padding top: Adjust the top vertical spacing on desktop screens (in pixels, e.g., 60 px).
    • Padding bottom: Adjust the bottom vertical spacing on desktop screens (in pixels, e.g., 60 px).
  • Mobile padding:
    • Padding top: Adjust the top vertical spacing on mobile devices (in pixels, e.g., 40 px).
    • Padding bottom: Adjust the bottom vertical spacing on mobile devices (in pixels, e.g., 40 px).

FAQs

Where can I find the Build perfect set section?

From your Shopify admin, go to Online Store > Themes and click Customize. In the template sidebar, locate Build perfect set or click Add section > Build perfect set to add it to your page.

How does the interactive set builder work for shoppers?

Shoppers click ADD TO SET or CHOOSE OPTIONS on any product card in the section. Selected items instantly populate the YOUR SET summary tray at the bottom, calculating the real-time total price. Clicking ADD TO CART adds all selected bundle products to the cart in a single step.

How do I configure the number of allowed items in a set?

In the section settings under Products, adjust the Set slots slider (e.g., 2, 3, or 4 slots). This determines the number of empty slot placeholders shown in the summary tray for customers to fill.

Can shoppers choose product variants (like ring size or metal type)?

Yes. When a product has variants, clicking CHOOSE OPTIONS allows the customer to pick their desired variant before adding the piece to their active set slot.

How can customers remove an item from their set?

Customers can click the small close icon (×) on any filled slot in the summary tray or click the SELECTED button again on the product card to deselect it and free up the slot.
