Promo banner

The Promo banner section is a dynamic promotional feature designed for limited-time offers, flash sales, and spotlight collections. It combines an interactive circular Image wheel of product thumbnail cards on the left with an expansive full-width background banner on the right, complete with an integrated real-time countdown timer and direct call-to-action button.

Configure promo banner Try the theme

Setup

Promo banner Section Settings

Configure section-wide settings such as the color scheme, dark overlay opacity, image wheel geometry (radius, angle, and horizontal alignment), and desktop/mobile spacing.

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the template sidebar, select Promo banner (or click Add section → Promo banner).
  • Choose a Color scheme and adjust the Overlay opacity percentage slider for optimal readability.
  • Under Image wheel, adjust the Wheel radius, Angle between images, and Wheel position from left sliders to customize the carousel curve.
  • Click Add Promo in the sidebar to create promotional slide blocks.
  • Upload the Thumb image and Banner image, enter the Heading, configure the Countdown end date, and set up your Button link.
  • Adjust Desktop spacing and Mobile spacing sliders and click Save.
  • Color scheme: Select a predefined theme color palette (e.g., Scheme 1, Scheme 2, etc.) to set background and typography color styling for the section. Click Edit scheme to customize colors directly.
  • Overlay opacity: Adjust the background overlay darkness percentage using the slider (e.g., 40%) to ensure headlines and countdown timers stand out clearly over the banner image.
  • Image wheel:
    • Wheel radius: Adjust the circular curve radius in rem units using the slider (e.g., 85 rem). Larger values create a gentler, flatter curve for thumbnail cards.
    • Angle between images: Adjust the angular separation in degrees between adjacent thumbnail cards along the wheel (e.g., 20°).
    • Wheel position from left: Adjust the horizontal placement offset of the active centered thumbnail from the left margin (e.g., 20 rem).
  • Desktop spacing:
    • Padding top: Adjust the top vertical spacing on desktop viewports (in pixels, e.g., 40 px).
    • Padding bottom: Adjust the bottom vertical spacing on desktop viewports (in pixels, e.g., 40 px).
  • Mobile spacing:
    • Padding top: Adjust the top vertical spacing on mobile screens (in pixels, e.g., 30 px).
    • Padding bottom: Adjust the bottom vertical spacing on mobile screens (in pixels, e.g., 30 px).

Blocks

Promo Block Settings

  • Promo: Each promo block represents an individual promotional campaign slide combining a thumbnail on the left wheel, a full-size background banner, headline typography, live countdown timer, and call-to-action button.
    • Thumb image: Upload or select the transparent product cutout or square thumbnail graphic displayed on the circular wheel (e.g., Rectangle_45420.png).
    • Banner image: Upload or select the full-resolution background lifestyle photo displayed behind the promotion (e.g., Rectangle_45268.jpg).
    • Heading: Enter the main promotional headline text (for example: TIMELESS ELEGANCE AT SPECIAL PRICES). Supports dynamic source connections.
    • Heading size: Select the font size scale level for the headline (e.g., H1, H2, H3, H4, H5).
    • Countdown:
      • Show countdown timer: Toggle on to display the real-time Days, Hours, Minutes, and Seconds countdown clock on this promotional slide.
      • End date & time: Enter the target expiration timestamp in 24-hour format (Format: YYYY-MM-DD HH:MM, for example: 2026-09-31 23:59). The countdown automatically synchronizes with each visitor's local timezone. Supports dynamic source connections.
    • Button:
      • Button label: Enter the label text displayed on the call-to-action button (for example: Explore more). Supports dynamic source connections.
      • Button link: Select or paste the target URL, product page, or collection destination (e.g., Full Pavé Diamond Double Band Ring).
      • Open link in new tab: Toggle on to open the destination link in a new browser tab.
      • Button style: Choose the visual styling for the button (e.g., Link, Primary, Secondary, or Outline).
