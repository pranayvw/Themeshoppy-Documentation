Video reviews

The Video reviews section allows you to build social proof and customer trust by presenting authentic video testimonials and user-generated reviews in an editorial mosaic layout. Visitors can see customer star ratings, read quotes, and watch high-definition video reviews of your jewellery collections.

Configure video reviews Try the theme

Setup

Video reviews Section Settings

Configure section-wide settings such as the color scheme, full-width display toggle, typography, overlay text colors, and responsive viewport spacing.

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the template sidebar, select Video reviews (or click Add section → Video reviews).
  • Choose a Color scheme and toggle Make section full width if desired.
  • Enter the section Heading, choose a Font size, and enter narrative Description copy.
  • Set the card overlay Text color (e.g., #FFFFFF).
  • Click + Add Video review in the sidebar to add review blocks.
  • For each block, choose its Column (Left, Center, Right), upload your Video file, set the Star rating, and enter the Customer name and Review text.
  • Adjust Desktop spacing and Mobile spacing sliders and click Save.
  • Color scheme: Select a predefined theme color palette (e.g., Scheme 1, Scheme 2, etc.) to set the background and text styling for the section. Click Edit scheme to customize colors directly.
  • Make section full width: Toggle on to expand the video review mosaic across the full viewport width without container page margins.
  • Heading: Enter the main section headline displayed at the top (for example: REAL THOUGHTS). Supports dynamic source connections.
  • Font size: Select the heading typography scale (e.g., H1, H2, H3, H4, H5).
  • Description: Enter supporting narrative copy introducing the video feedback (for example: Experience real customer feedback through video testimonials, highlighting exceptional quality, elegant designs, and lasting satisfaction.). Supports rich text formatting (bold, italic, links) and dynamic source connections.
  • Color:
    • Text color: Choose the font color for the customer name and review text overlay badges (for example: #FFFFFF).
  • Desktop spacing:
    • Padding top: Adjust the top vertical spacing on desktop screens (in pixels, e.g., 80 px).
    • Padding bottom: Adjust the bottom vertical spacing on desktop screens (in pixels, e.g., 80 px).
  • Mobile spacing:
    • Padding top: Adjust the top vertical spacing on mobile screens (in pixels, e.g., 40 px).
    • Padding bottom: Adjust the bottom vertical spacing on mobile screens (in pixels, e.g., 40 px).

Blocks

Video Review Block Settings

  • Video review: Each block represents an individual video testimonial card positioned within the 3-column mosaic grid.
    • Column: Select which column within the mosaic layout this video card will be placed into (Left, Center, or Right).
    • Size: Select the display size format (e.g., Large (center column) or Regular). Large only applies inside the center column, spanning both sub-columns like a feature hero video.
    • Media:
      • Image: Upload or select an optional custom poster/cover image displayed before the video starts playing.
      • Video: Upload or select an MP4 video file from your Shopify files library (e.g., v5.mp4).
      • Autoplay video: Toggle on to automatically play the video in an infinite muted loop when visible on screen.
    • Review:
      • Star rating: Set the customer review rating using the slider (from 1 to 5 stars, e.g., 5).
      • Customer name: Enter the customer or reviewer's name (for example: GRACE MITCHELL). Supports dynamic source connections.
      • Review text: Enter the detailed customer feedback text or quote narrative (for example: I appreciate the premium materials and flawless finishing throughout the piece. The jewelry feels comfortable enough for daily wear while maintaining a luxurious appearance...).
