Scrolling showcase

The Scrolling showcase section (also known as an infinite brand logo marquee or ticker) creates a continuous, smoothly animated horizontal ribbon across your storefront. It is designed to spotlight prestigious partner brands, luxury watchmakers, jewellery designers, media press mentions, or trust certifications (such as PIAGET, Chopard, Christian Dior, Tiffany & Co., Jacob & Co., and Bvlgari) with adjustable speed, spacing, and interactive pause controls.

Scrolling showcase Section Settings

Configure section-wide settings such as the ticker appearance (image border radius, space between items, caption size, image dimensions, and scrolling speed), inner spacing, and desktop/mobile padding.

Steps

  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the template sidebar, select Scrolling showcase (or click Add section → Scrolling showcase).
  • Under Ticker appearance, adjust Image size, Space between items, Ticker speed, Caption size, and Image border radius.
  • Configure Inner spacing (Top & Bottom spacing) for internal padding.
  • Click Add Ticker item in the sidebar to add brand logos or partner badges.
  • Upload the Image (SVG or transparent PNG) and enter an optional Caption for each item.
  • Adjust Desktop padding and Mobile padding sliders and click Save.
  • Ticker appearance:
    • Image border radius: Adjust the corner curvature applied to ticker images (slider in pixels, e.g., 0 px).
    • Space between items: Control the horizontal gap between adjacent logo items (slider in pixels, e.g., 100 px).
    • Caption size: Set the font size for text captions displayed beneath or beside logos (slider in pixels, e.g., 20 px).
    • Image size: Set the display width for brand logo images (slider in pixels, e.g., 200 px).
    • Ticker speed: Adjust the speed of the horizontal scrolling animation (slider scale, e.g., 20). Higher values increase scrolling speed.
  • Inner spacing:
    • Top spacing: Adjust inner vertical spacing above the ticker container (e.g., 20).
    • Bottom spacing: Adjust inner vertical spacing below the ticker container (e.g., 20).
  • Desktop padding:
    • Padding top: Set top vertical spacing on desktop screens (slider in pixels, e.g., 0 px).
    • Padding bottom: Set bottom vertical spacing on desktop screens (slider in pixels, e.g., 20 px).
  • Mobile padding:
    • Padding top: Set top vertical spacing on mobile screens (slider in pixels, e.g., 0 px).
    • Padding bottom: Set bottom vertical spacing on mobile screens (slider in pixels, e.g., 20 px).

Ticker item Block Settings

  • Ticker item: Each ticker item block represents an individual brand logo, media partner, or trust certification displayed in the marquee stream.
    • Image: Upload the brand logo or emblem (e.g., ChristianDior.svg, Piaget.svg, or high-resolution PNG with a transparent background).
    • Caption: Enter optional accompanying descriptive text or brand name (e.g., Featured text). Supports dynamic source connections.

FAQs

Where can I find and add the Scrolling showcase section?

From your Shopify admin, go to Online Store > Themes and click Customize. In the template sidebar, click Add section > Scrolling showcase to add the infinite logo marquee to your homepage, about page, or product pages.

What image formats work best for brand logos?

Vector SVG files or high-resolution PNG images with transparent backgrounds deliver the crispest rendering across high-density Retina displays.

How do I control the speed and gap between logos?

Under Ticker appearance in the section settings, use the Ticker speed slider to speed up or slow down movement, and the Space between items slider to increase or reduce spacing between logos.

Can shoppers pause the scrolling marquee?

Yes. An interactive pause/play button (||) is embedded alongside the marquee ribbon, allowing visitors to freeze motion for ease of viewing.
