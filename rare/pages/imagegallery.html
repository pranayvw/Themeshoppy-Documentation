Image gallery

The Image gallery section delivers a captivating visual carousel to showcase curated photoshoots, brand lookbooks, community highlights, or Instagram feeds directly on your storefront (such as FOLLOW OUR SPARKLING JOURNEY). Featuring smooth touch-friendly slider navigation, configurable slides per view for desktop and mobile, aspect ratio controls, customizable corner radius, and direct link attachments for every image slide, it drives visual engagement and connects customers directly with your brand stories and social channels.

Setup

Image gallery Section Settings

Configure section-wide settings including the header icon/badge image, slider layout controls (desktop and mobile slide counts, slide gap spacing, image aspect ratio, corner radius, pagination dots, and autoplay), as well as responsive desktop and mobile padding.

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the template sidebar, select Image gallery (or click Add section → Image gallery).
  • Upload an optional Image (such as an Instagram icon SVG) to display above the section heading.
  • Under Slider layout, set the number of Slides on desktop (e.g., 5) and Slides on mobile (e.g., 1.5).
  • Adjust Space between slides (e.g., 16 px), choose an Image ratio (e.g., Portrait), and adjust Corner radius (e.g., 0 px).
  • Toggle Show pagination dots and Enable autoplay according to your preference.
  • Click + Add Image in the sidebar to add image slides to the gallery.
  • For each image slide, upload the photo, add a destination Link, toggle Open link in new tab, and optionally add a Caption.
  • Adjust Desktop padding and Mobile padding sliders and click Save.
  • Image: Upload or select an icon/graphic badge (such as an Instagram logo SVG fi_1384063.svg or brand icon) displayed centered above the section title.
  • Slider layout:
    • Slides on desktop: Set the number of slides visible simultaneously in the carousel on desktop screens using the slider (e.g., 5).
    • Slides on mobile: Set the number of slides visible at once on mobile devices using the slider (e.g., 1.5 for a partial next-slide preview effect).
    • Space between slides: Adjust the gap spacing between adjacent slides in pixels using the slider (e.g., 16 px).
    • Image ratio: Choose the display aspect ratio for gallery images (Portrait, Square, Landscape, or Adapt to image).
    • Corner radius: Control the rounded corner curvature for gallery images in pixels using the slider (e.g., 0 px for crisp edges or higher values for rounded cards).
    • Show pagination dots: Toggle on to display clickable navigation dot indicators beneath the carousel slider.
    • Enable autoplay: Toggle on to allow gallery slides to transition automatically in a continuous loop.
  • Desktop padding:
    • Padding top: Adjust top vertical spacing on desktop screens (in pixels, e.g., 60 px).
    • Padding bottom: Adjust bottom vertical spacing on desktop screens (in pixels, e.g., 0 px).
  • Mobile padding:
    • Padding top: Adjust top vertical spacing on mobile screens (in pixels, e.g., 40 px).
    • Padding bottom: Adjust bottom vertical spacing on mobile screens (in pixels, e.g., 40 px).
  • Custom CSS: Add custom CSS rules directly within the Theme Editor to further fine-tune or override styling for this section.

Blocks

Image Block Settings

  • Image: Each block represents an individual photo slide displayed within the gallery carousel.
    • Image: Upload or select the high-resolution photograph to display in this gallery slide (e.g., Rectangle_55.jpg).
    • Link: Select or enter a destination URL (e.g., an Instagram page https://www.instagram.com/shopify, product page, collection, or custom URL) so visitors are redirected upon clicking the slide. Supports dynamic source connections.
    • Open link in new tab: Toggle on to open the linked URL in a separate browser tab, keeping your online store open in the customer's original tab.
    • Caption: Enter optional text to display as a caption or label for the image slide. Supports dynamic source connections.
