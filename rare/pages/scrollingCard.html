Scrolling cards

The Scrolling cards section delivers an immersive, editorial storytelling experience on your storefront. As customers scroll down the page, central product or lookbook cards move gracefully into view flanked by bold typographical keywords and optional floating decorative accent images on either side.

Configure scrolling cards Try the theme

Setup

Scrolling cards Section Settings

Configure section-wide color schemes, heading font sizes, and responsive viewport padding for the Scrolling cards section.

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the template sidebar, locate Scrolling cards (or click Add section → Scrolling cards).
  • Select your preferred Color scheme for the section background and text.
  • Choose the Font size for the flanking word titles (e.g., Extra large).
  • Adjust Desktop padding and Mobile padding sliders to control spacing.
  • Click Save to apply your changes.
  • Color scheme: Select a predefined theme color palette (e.g., Scheme 1, Scheme 2, etc.) to set background and typography styling for the entire section. Click Edit scheme to customize colors directly.
  • Font size: Select the font size scale for the left and right flanking headline words (e.g., Extra large, Large, Medium, or Small).
  • Desktop padding:
    • Padding top: Adjust the top vertical spacing on desktop screens (in pixels, e.g., 62 px).
    • Padding bottom: Adjust the bottom vertical spacing on desktop screens (in pixels, e.g., 62 px).
  • Mobile padding:
    • Padding top: Adjust the top vertical spacing on mobile screens (in pixels, e.g., 0 px).
    • Padding bottom: Adjust the bottom vertical spacing on mobile screens (in pixels, e.g., 0 px).

Blocks

Showcase Item Block Settings

  • Showcase item: Each showcase item block represents an individual scrolling card slide consisting of a left column with a keyword and optional decorative image, a center card image with a link and description, and a right column with a keyword and optional decorative image.
    • Left column:
      • Left word: Enter the keyword or title text displayed on the left side (for example: GOLDEN). Supports dynamic source connections.
      • Color: Choose a custom color for the left word text (for example: #B6303A).
      • Show left image: Toggle on to display a decorative image alongside the left word.
      • Image position: Choose whether the left decorative image is positioned at the Top or Bottom relative to the word.
      • Left decorative Image: Upload or select an accent product graphic or decorative image for the left side.
      • Image width: Adjust the relative display width percentage of the left decorative image using the slider (for example: 60%).
    • Center column:
      • Card Image: Upload or select the main high-quality card photograph (for example, a jewellery model shot or product lookbook photo).
      • Card description: Enter optional rich text description copy displayed alongside or beneath the card image.
      • Image link: Connect a clickable link (e.g., a specific collection such as Rings, a product page, or an external URL) to make the center card interactive. Supports dynamic source connections.
    • Right column:
      • Right word: Enter the keyword or title text displayed on the right side (for example: GRACE). Supports dynamic source connections.
      • Color: Choose a custom color for the right word text (for example: #C77278).
      • Show right image: Toggle on to display a decorative image alongside the right word.
      • Image position: Choose whether the right decorative image is positioned at the Top or Bottom relative to the word.
      • Right decorative Image: Upload or select an accent product graphic or decorative image for the right side.
      • Image width: Adjust the relative display width percentage of the right decorative image using the slider (for example: 70%).
