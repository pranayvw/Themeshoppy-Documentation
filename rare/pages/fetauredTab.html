Theme documentation

Featured tab

The Featured tab section allows you to organize and present multiple product collections in an intuitive, tabbed showcase. Customers can effortlessly switch between curated product categories—such as Rings, Bracelets, Earrings, and Necklaces—using visual image tabs placed at the top or left of the section.

Setup

Featured tab Section Settings

Featured tab Section Settings

Configure section-wide settings such as the color scheme, tab button placement, heading, font size, description, product count, grid columns, slider enablement, product card display features (quick view, swatches, secondary image on hover), and desktop/mobile spacing.

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the Template sidebar, select Featured tab (or click Add section → Featured tab).
  • Choose a Color scheme and select the Tab button position (Top or Left).
  • Customize the Heading, Font size, and Description.
  • Set the number of Products to show, Columns per row, and toggle Enable slider if desired.
  • Configure Product cards options (Image aspect ratio, secondary hover image, vendor, quick view, variant swatches, view all button, and button style).
  • Adjust Desktop padding and Mobile padding for optimal section spacing.
  • Click Save to apply your changes.
  • Color scheme: Select a predefined theme color scheme (e.g., Scheme 1, Scheme 2, etc.) to apply consistent background and typography colors to the section. Click Edit scheme to customize scheme colors directly.
  • Tab button position: Choose the alignment layout for the collection tab buttons:
    • Top: Positions tab buttons horizontally above the product grid/slider.
    • Left: Positions tab buttons vertically alongside the product grid/slider.
  • Heading: Enter the primary headline displayed above or alongside the tabs (for example: BROWSE LUXURY). Supports dynamic source connections.
  • Font size: Select the heading level / size (e.g., H1, H2, H3, H4, H5, H6) to control typography hierarchy.
  • Description: Enter supporting narrative copy or promotional text displayed beside or beneath the heading (for example: Explore premium jewellery crafted with exquisite attention to detail, combining modern sophistication with timeless luxury.). Supports rich text styling (bold, italic, and links).
  • Products to show: Adjust the slider to set how many products are loaded per active collection tab (for example: 5).
  • Columns per row: Set the number of product columns displayed per row on desktop screens (for example: 5 col).
  • Enable slider: Toggle on to arrange products in a swipeable horizontal carousel instead of a static grid.
  • Product cards: Configure how individual product cards look and behave:
    • Image aspect ratio: Select the aspect ratio for product images (e.g., Square, Portrait, Landscape, Adapt to image).
    • Show secondary image on hover: Toggle on to reveal the second product media image when visitors hover over the card.
    • Show vendor: Toggle on to display the product brand/vendor name above the title.
    • Enable quick view: Allow shoppers to click a quick view icon to preview product options in a modal popup without leaving the page.
    • Show variant swatches: Display color/material swatch dots directly on product cards for fast variant previewing.
    • Show view all: Toggle on to display a "View all" button linking to the full collection page.
    • Button style: Choose between Primary and Secondary button styling.
  • Desktop padding:
    • Padding top: Adjust the top vertical spacing of the section on desktop screens (in pixels, e.g., 60 px).
    • Padding bottom: Adjust the bottom vertical spacing of the section on desktop screens (in pixels, e.g., 40 px).
  • Mobile padding:
    • Padding top: Adjust the top vertical spacing of the section on mobile devices (in pixels, e.g., 40 px).
    • Padding bottom: Adjust the bottom vertical spacing of the section on mobile devices (in pixels, e.g., 40 px).

Tabs

Tab Block Settings

Tab Block Settings

Each Tab block represents an individual collection tab within the section. You can link a Shopify collection, enter a custom title label, and upload a custom thumbnail icon.

Steps
  • Under Featured tab in the left sidebar, click Add Tab or select an existing Tab block.
  • Optionally enter a Tab title (or leave blank to display the collection title).
  • Upload or select an Icon image for the tab button.
  • In Select collection, choose the Shopify collection to display in this tab.
  • Click Save to apply your changes.
  • Tab title (optional): Enter a custom title label displayed on the tab button (for example: RINGS). If left blank, the section will automatically use the collection's title. Supports dynamic source connections.
  • Icon: Upload or select an image thumbnail to display inside the tab button for visual recognition (for example: an image of a ring, bracelet, or necklace).
  • Select collection: Choose which Shopify collection from your store catalog to load and display in this tab (e.g., Rings, Bracelets, Earrings, Necklaces).
