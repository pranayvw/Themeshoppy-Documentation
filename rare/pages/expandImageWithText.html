Expanding image with text

The Expanding image with text section is an interactive visual storytelling feature that creates a scroll-triggered dynamic expansion animation. As visitors scroll down the page, the feature image smoothly expands in width and morphs between custom aspect ratios while keeping your brand story, narrative copy, and call-to-action button perfectly aligned alongside the visual.

Expanding image with text Section Settings

Configure section-wide settings such as the color scheme, feature image, layout alignment (image on left or right), content vertical position, scroll animation width boundaries, and responsive image shapes.

Steps

  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the template sidebar, select Expanding image with text (or click Add section → Expanding image with text).
  • Select your desired Color scheme and upload your high-resolution feature Image.
  • Toggle Put the image on the right if you prefer the visual positioned on the right side.
  • Choose your Content position (Top, Middle, or Bottom).
  • Under Scroll animation, set the Image start width (e.g., 30%) and Image end width (e.g., 62%).
  • Under Image shape, select the Start shape (e.g., Portrait (3:4)) and End shape (e.g., Landscape (4:3)), as well as the Mobile shape.
  • Add and configure child blocks (Heading, Text, and Button) in the sidebar.
  • Adjust Desktop spacing and Mobile spacing sliders and click Save.
  • Color scheme: Select a predefined theme color palette (e.g., Scheme 1, Scheme 2, etc.) to set background surfaces, card colors, and typography styling. Click Edit scheme to customize palette colors directly.
  • Image: Upload or select the primary lifestyle photo or feature visual (e.g., f47d95d941...d5462.jpg).
  • Put the image on the right: Toggle switch to position the image on the right side and text content on the left side. When unchecked, the image displays on the left and text on the right.
  • Content position: Select the vertical alignment of the text column relative to the image (choose Top, Middle, or Bottom; set to Middle).
  • Scroll animation:
    • Image start width: Set the initial width percentage of the image container before scrolling begins (slider, e.g., 30 %).
    • Image end width: Set the maximum expanded width percentage reached as the visitor scrolls down (slider, e.g., 62 %). Note: Must be larger than the start width.
  • Image shape:
    • Start shape: Select the initial aspect ratio geometry before scrolling (choose Portrait (3:4), Square (1:1), Landscape (4:3), or Adapt to image).
    • End shape: Select the final expanded aspect ratio geometry achieved at the end of the scroll animation (choose Landscape (4:3), Square (1:1), or Portrait (3:4)).
  • Mobile:
    • Image shape: Select the aspect ratio geometry used on mobile viewports (choose Portrait (3:4), Square (1:1), or Landscape (4:3)).
  • Desktop spacing:
    • Padding top: Set the top vertical spacing on desktop viewports (slider in pixels, e.g., 0 px).
    • Padding bottom: Set the bottom vertical spacing on desktop viewports (slider in pixels, e.g., 40 px).
  • Mobile spacing:
    • Padding top: Set the top vertical spacing on mobile screens (slider in pixels, e.g., 0 px).
    • Padding bottom: Set the bottom vertical spacing on mobile screens (slider in pixels, e.g., 30 px).

Heading Block Settings

  • Heading: Enter the main section headline text (for example: Our Vison). Supports rich text formatting (bold, italic, links) and dynamic source connections.
  • Heading size: Choose the typography scale level for the headline (select from H1, H2, H3, H4, or H5).

Text Block Settings

  • Text: Enter supporting narrative copy and paragraph text (for example: Driven by a passion for exceptional craftsmanship, we create jewelry that blends timeless elegance with contemporary design...). Supports full rich text formatting (bold, italic, links, bulleted and numbered lists) and dynamic sources.

Button Block Settings

  • Button label: Enter the label text displayed on the call-to-action button (for example: Explore). Supports dynamic source connections.
  • Button link: Select or paste the target URL, product page, collection, or custom destination (e.g., #).
  • Open link in new tab: Toggle on to open the link destination in a new browser tab.
  • Button style: Choose the visual styling for the button (choose Primary, Secondary, Outline, or Link; set to Primary).

FAQs

Where can I find and add the Expanding image with text section?

From your Shopify admin, go to Online Store > Themes and click Customize. In the template sidebar, click Add section > Expanding image with text to add the section to your About page, homepage, or custom landing pages.

How does the scroll animation work?

As visitors scroll past the section, the image smoothly expands from the Image start width (e.g., 30%) to the Image end width (e.g., 62%) and transitions its shape (e.g., from Portrait 3:4 to Landscape 4:3) based on scroll progress.

What happens if Image End Width is smaller than Start Width?

The Image end width must always be configured with a value larger than the Image start width to ensure proper scroll-triggered expansion animation.

Can I position the image on the right side instead of the left?

Yes. Simply toggle the Put the image on the right setting to invert the layout, placing the expanding image on the right and the text narrative on the left.
