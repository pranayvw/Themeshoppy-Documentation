Scrolling zoom

The Scrolling zoom section delivers an immersive, interactive visual journey. As the user scrolls down the page, floating surrounding images zoom and disperse outward while a central focal point (image or looped video) and split headline (Left word / Right word) emerge into full view with a call-to-action button.

Configure scrolling zoom Try the theme

Setup

Scrolling zoom Section Settings

Configure section-wide settings such as the color scheme, split title text (left and right words), center media (image or background video), call-to-action button, scroll length animation duration, and desktop/mobile spacing.

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the Template sidebar, select Scrolling zoom (or click Add section → Scrolling zoom).
  • Choose a Color scheme and configure the split Title (Left word and Right word).
  • Upload the Center image or select a Center video.
  • Configure the Button settings (Button label, Button link, Button style, and Open link in new tab).
  • Adjust the Scroll length under Scroll behavior to control animation speed.
  • Configure Desktop spacing and Mobile spacing (Space above and Space below).
  • Click Save to apply your changes.
  • Color scheme: Select a predefined theme color scheme (e.g., Scheme 1, Scheme 2, etc.) to set the background and typography colors for the section. Click Edit scheme to customize the scheme's colors.
  • Title:
    • Left word: Enter the first/left text portion of the section headline (for example: TIMELESS).
    • Right word: Enter the second/right text portion of the section headline (for example: SPARKLE).
  • Center media:
    • Center image: Upload the primary focal image displayed in the center of the zoom animation.
    • Center video: Upload or select an MP4 video file. When set, the video overrides the center image and plays automatically in a muted, infinite loop.
  • Button:
    • Button label: Enter the text for the call-to-action button (for example: EXPLORE NOW).
    • Button link: Select or paste the URL destination for the button (for example: a featured product or collection).
    • Open link in new tab: Toggle on to open the destination link in a new browser tab.
    • Button style: Choose the design appearance for the button (e.g., Link, Primary, or Secondary).
  • Scroll behavior:
    • Scroll length: Adjust the slider to define the scroll duration in viewport height units (e.g., 250 vh). This determines how much the user scrolls while the zoom animation plays (higher values produce a slower, more gradual zoom effect).
  • Desktop spacing:
    • Space above: Set the margin/spacing above the section on desktop screens (in pixels, e.g., 0 px).
    • Space below: Set the margin/spacing below the section on desktop screens (in pixels, e.g., 0 px).
  • Mobile spacing:
    • Space above: Set the margin/spacing above the section on mobile devices (in pixels, e.g., 0 px).
    • Space below: Set the margin/spacing below the section on mobile devices (in pixels, e.g., 0 px).

Images

Image Block Settings

You can add up to 8 Image blocks to the Scrolling zoom section. Each image block represents a floating ambient photo positioned across the canvas that disperses as the visitor scrolls.

Steps
  • Under Scrolling zoom in the left sidebar, click Add Image or select an existing Image block.
  • Upload or select the Image.
  • Choose an Image aspect ratio.
  • Optionally attach a destination Link to make the image clickable.
  • Adjust the position coordinates (Position from top and Position from left) and Width percentage.
  • Click Save to apply your changes.
  • Image: Upload or select the photo to display as a floating ambient visual in the zoom canvas.
  • Image aspect ratio: Select the aspect ratio for the image (e.g., Adapt to image, Square, Portrait, or Landscape).
  • Link: Optional URL or page destination when clicking the image.
  • Position from top: Adjust the vertical position of the image on the canvas as a percentage from the top edge (e.g., 65 %).
  • Position from left: Adjust the horizontal position of the image on the canvas as a percentage from the left edge (e.g., 58 %).
  • Width: Set the relative width scale of the image as a percentage of the section container (e.g., 24 %).
