Theme documentation

Image with text

The Image with text section pairs high-impact editorial photography with refined typography and call-to-action buttons (such as LUXURY CRAFTED TO CELEBRATE EVERY MOMENT). It is ideal for sharing your brand's heritage, spotlighting artisan craftsmanship, highlighting signature jewelry collections, or guiding visitors to key landing pages with a clean, balanced two-column layout.

Setup

Image with text Section Settings

Configure global section settings including color schemes, section width, inner padding and background toggles, image selection, aspect ratio, image position (left or right), content alignment, and responsive viewport spacing.

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the template sidebar, select Image with text (or click Add section → Image with text).
  • Choose a Color scheme for the section background and text.
  • Select the Section width (Container width or Full width) and toggle Enable inner padding or Enable inner background if desired.
  • Under Image, upload your photograph (e.g., Rectangle_45466.jpg), choose the Aspect ratio (e.g., Adapt to image), and set the Image position (Left or Right).
  • Set the Text alignment (Left, Center, or Right).
  • Configure the child blocks: enter your section Heading and choose a Font size, add supporting Description text, and customize the Button label, link, and style.
  • Adjust Desktop spacing and Mobile spacing sliders and click Save.
  • Color scheme: Select a predefined theme color palette (e.g., Scheme 1, Scheme 2, etc.) to control background and text colors. Click Edit scheme to customize colors directly.
  • Section width: Choose the layout container width (Container width for a standard bounded page container, or Full width for edge-to-edge display).
  • Enable inner padding: Toggle on to add additional inner padding surrounding the content container.
  • Enable inner background: Toggle on to apply an enclosed background color fill behind the content area.
  • Image:
    • Image: Upload or select the primary high-resolution photograph (e.g., Rectangle_45466.jpg).
    • Aspect ratio: Choose the display ratio for the image (Adapt to image, Portrait, Square, or Landscape).
    • Image position: Choose whether the image appears on the Left or Right side of the text column on desktop screens.
    • Text alignment: Set the alignment of the text content and button (Left, Center, or Right).
  • Desktop spacing:
    • Padding top: Adjust top vertical spacing on desktop screens (in pixels, e.g., 40 px).
    • Padding bottom: Adjust bottom vertical spacing on desktop screens (in pixels, e.g., 40 px).
  • Mobile spacing:
    • Padding top: Adjust top vertical spacing on mobile screens (in pixels, e.g., 30 px).
    • Padding bottom: Adjust bottom vertical spacing on mobile screens (in pixels, e.g., 30 px).

Blocks

Image with Text Block Settings

The Image with text section contains customizable child blocks to structure your narrative copy and call-to-action.

Heading Block

The Heading block displays the primary title for the section.

  • Heading: Enter the main section headline (for example: LUXURY CRAFTED TO CELEBRATE EVERY MOMENT). Supports rich text formatting (bold, italic, links) and dynamic source connections.
  • Font size: Select the typography scale for the heading (H1, H2, H3, H4, or H5, e.g., H4).

Description Block

The Description block adds rich supporting narrative content below the heading.

  • Description: Enter descriptive storytelling copy highlighting your brand values, materials, or styling guidance (for example: Designed for milestones and unforgettable memories, our jewelry combines refined craftsmanship with timeless beauty, creating heirloom-quality pieces you'll cherish forever.). Supports rich text formatting (bullet lists, numbered lists, bold, italic, links) and dynamic source connections.

Button Block

The Button block adds a call-to-action button to direct visitors to relevant pages.

  • Button label: Enter the text displayed on the button (for example: Explore more). Supports dynamic source connections.
  • Button link: Enter or search for the destination URL (e.g., a specific collection, product page, or external link). Supports dynamic source connections.
  • Button style: Choose the button visual appearance (Primary or Secondary).
  • Open link in new tab: Toggle on to open the button destination in a separate browser tab.
