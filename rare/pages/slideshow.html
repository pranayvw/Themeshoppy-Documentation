Slideshow Hero

The Slideshow hero section delivers a high-impact, luxury hero banner designed to showcase your brand's top collections, video lookbooks, and seasonal campaigns. Featuring a sophisticated three-part visual layout with flanking lifestyle photography and a dynamic center image or looped video, this section instantly elevates the storefront experience.

Slideshow Hero Section Settings

Configure global slideshow behavior including video auto-advance rules, navigation buttons, slider arrows, pagination dots, and mobile scroll prompts.

Steps

  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the Template sidebar, select Slideshow hero (or click Add section → Slideshow hero).
  • Configure video autoplay, button style, slider arrows, and slider dots.
  • Click Save to apply your changes.
  • Video autoplay:
    • Advance to next slide when video ends: Toggle this switch to automatically transition to the next slide when the center video completes playback. (Only applies to slides with a center video; stops if the visitor scrolls or manually interacts with the arrows).
  • Button:
    • Button style: Choose the design style for slide call-to-action buttons (e.g. Link,Primary,Secondary).
  • Slider arrows:
    • Show slider arrows: Toggle on or off directional arrow controls on either side of the slideshow.
    • Arrow color: Select the arrow icon color (for example: #FFFFFF).
    • Arrow background: Set the background fill color of the arrow button (for example: #000000).
    • Arrow color on hover: Choose the arrow icon color when hovered (for example: #000000).
    • Arrow background on hover: Set the background fill color on hover (for example: #FFFFFF).
  • Slider dots:
    • Show slider dots: Toggle navigation indicator dots along the bottom of the slideshow.
    • Dot color: Set the default color for inactive dots (for example: #FFFFFF).
    • Active dot color: Choose the indicator color for the currently active slide (for example: #FFFFFF).
  • Mobile:
    • Scroll down label: Enter a custom prompt label displayed on mobile devices (for example: Scroll down) to invite shoppers to explore the page.

Slide Block Settings

Each Slide block within the Slideshow Hero represents an individual hero banner with its own left image, center media (image or video), right image, heading, description, and call-to-action link.

Steps

  • Under Slideshow hero in the left sidebar, click Add Slide or select an existing slide block.
  • Select a Color scheme for the slide.
  • Upload the Left image, Center image or video, and Right image.
  • Add your Button label, Button link, Heading, and Description text.
  • Click Save to apply your changes.
  • Color scheme: Select a predefined theme color scheme (e.g. Scheme 1, Scheme 2, etc.) to style the slide's text and background.
  • Left side:
    • Left image: Upload the portrait or lifestyle photograph displayed on the left pane.
    • Invert bottom content style: Toggle to invert the color styling of bottom content and text elements.
  • Center image or video:
    • Image: Upload a primary product or campaign image for the center frame.
    • Video: Select an MP4 video file. If provided, the video replaces the center image and plays muted in an infinite loop, using the image above as its loading poster.
    • Button label: Enter the button text (for example: EXPLORE).
    • Button link: Paste a URL or search for a collection/product to link the button.
    • Open link in new tab: Toggle whether the link opens in a new browser tab.
  • Right side:
    • Right image: Upload the complementary image displayed on the right pane of the slide.
  • Slide text:
    • Heading: Enter the main headline displayed over the slide (for example: TIMELESS BEAUTY).
    • Description: Add descriptive storytelling copy or promotional highlights.
    • Font size: Select the heading level and font scaling (e.g. H1, H2, H3, or H4).

FAQs

Can I use both an image and a video in the center pane?

Yes. When you upload both an image and a video, the video will automatically play in the center pane while the static image acts as a fallback poster image while the video loads.

How do I make the slideshow automatically advance to the next slide?

In the Slideshow hero section settings, enable the Advance to next slide when video ends option under Video autoplay.

How many slides can I add to the Slideshow Hero?

You can add multiple slide blocks by clicking Add Slide in the Theme Editor sidebar. Shoppers can navigate through slides using the navigation arrows or bottom pagination dots.
