Collection list

The Collection list section allows you to feature and showcase curated product collections with custom images, bold headlines, descriptive copy, and stylish slanted cards. It gives customers a quick and visually compelling way to browse essential categories like Rings, Bracelets, Necklaces, and Earrings directly from the storefront.

Setup

Collection list Section Settings

Configure section-level settings to customize the color scheme, heading text, font size, description, collection card layout (including image aspect ratio, columns per row, and grid vs. slider view), and active navigation dot colors.

Steps
  • From your Shopify admin, go to Online Store → Themes .
  • Click Customize to open the Theme Editor.
  • In the Template sidebar, select Collection list (or click Add section → Collection list ).
  • Customize the Color scheme , Heading , Font size , and Description .
  • Under Collection layout , choose the Image size , set Desktop view columns, select Mobile columns , and choose between Grid or Slider layout.
  • Under Navigation dots , set the Active color for slider pagination.
  • Configure the Button settings (Button label, Button link, Button style, and Open link in new tab).
  • Adjust Desktop padding and Mobile padding for optimal section spacing.
  • Click Save to apply your changes.
  • Color scheme: Select a predefined theme color scheme (e.g., Scheme 1 , Scheme 2 , etc.) to set the background and text colors of the section. Click Edit scheme to customize the scheme's colors.
  • Heading: Enter the main section headline displayed above the collection items (for example: DISCOVER SPARKLES ). Supports rich text formatting such as bold, italic, and hyperlinks.
  • Font size: Select the heading level / size (e.g., H1 , H2 , H3 , H4 , H5 , H6 ) to control its typography scaling.
  • Description: Enter supporting narrative copy or promotional text displayed beside or beneath the heading (for example: Discover genuine customer experiences celebrating timeless craftsmanship, exceptional quality, and unforgettable jewellery moments together. ).
  • Collection layout:
    • Image size: Choose the display aspect ratio for collection images (e.g., Landscape , Portrait , Square , Adapt to image ).
    • Desktop view: Adjust the slider to specify the number of collection columns displayed per row on desktop screens (e.g., 4 ).
    • Mobile columns: Choose whether collection items appear in One or Two columns on mobile screens.
    • Layout type: Select how the collection cards are arranged:
      • Grid: Displays all collection items in a clean, responsive grid layout.
      • Slider: Displays collection items in a swipeable horizontal carousel with pagination dots.
  • Navigation dots:
    • Active color: Pick the color used for the active pagination dot indicator when the slider layout is enabled (e.g., #CD9D8F ).
  • Button:
    • Button label: Enter the text for an optional call-to-action button (e.g., View all collections ).
    • Button link: Paste a URL or search for a collection/page to link the button.
    • Button style: Choose between Primary and Secondary button designs.
    • Open link in new tab: Toggle on to open the button link in a new browser tab.
  • Desktop padding:
    • Padding top: Adjust the top spacing of the section on desktop screens (e.g., 70px ).
    • Padding bottom: Adjust the bottom spacing of the section on desktop screens (e.g., 40px ).
  • Mobile padding:
    • Padding top: Adjust the top spacing of the section on mobile devices (e.g., 40px ).
    • Padding bottom: Adjust the bottom spacing of the section on mobile devices (e.g., 40px ).

Collection items

Collection item Block Settings

Each Collection item block represents a specific collection card in the section. You can link a Shopify collection, upload a custom image or icon, and set an optional custom display title.

Steps
  • Under Collection list in the left sidebar, click Add Collection item or select an existing collection block.
  • In Select collection , choose the Shopify collection you want to display.
  • Under Collection image , upload or select a custom image for the card.
  • Optionally enter a custom Collection title or choose an Icon .
  • Click Save to apply your changes.
  • Select collection: Choose which Shopify collection this block links to (for example: Rings , Bracelets , Necklaces , Earrings ).
  • Collection image: Upload a custom featured image for the collection card. If left blank, the collection's default image from the Shopify admin will be used.
  • Collection title: Enter an optional custom title to override the default collection name. Supports dynamic source connections.
  • Icon: Select or upload a custom icon image to display with the collection item.
