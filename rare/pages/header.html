Header section

The Header is the first point of contact for your customers, making it essential for creating a lasting impression and reinforcing your brand identity. With Rare, you have full control over your header's layout and design, offering various options that seamlessly integrate with your store’s aesthetic.

The header includes elegantly designed icons for easy access to the cart, customer account, and search functionalities. To elevate your store’s navigation, Rare offers separate guides for configuring the Announcement Bar, Dropdown Menu, and Mega Menu, ensuring a streamlined experience for your customers.

Setup

Steps to Set Up the Header Section in Your Shopify Theme, Rare

How to Configure the Header

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Rare theme.
  • In the Theme Editor, select the Header section from the left sidebar.
  • Adjust the settings, blocks, and layout options according to your preferences.
  • Click Save to apply your changes.

Configuration

Follow these steps to configure your Header

  • Color scheme: Choose a color scheme to control the background and text colors of the header section.
  • Logo:
    • Logo: Upload your store logo using the Select logo option.
    • Logo width: Adjust the size of the logo displayed in the header using the width slider (for example, 120px).
    • Enable sticky header: Turn this option on if you want the header to remain fixed at the top of the page while scrolling.
    • Enable overlay: Enable this option to display the header on top of the hero banner (Only applies on the homepage).
    • Overlay logo: Select an alternate logo specifically for the transparent overlay header.
    • Overlay text color: Customize the text color (for example, #FFFFFF) used when the header overlay is active.
    • Logo position: Choose the layout positioning of the logo and navigation menu (for example, Logo center with menu...).
  • Menu:
    • Select menu: Choose the main navigation menu that will appear in the header (for example, Main menu).
  • Header inner padding: Controls spacing inside the header area (between header content and its border).
    • Top spacing: Adjust the inner spacing at the top of the header (for example, 4).
    • Bottom spacing: Adjust the inner spacing at the bottom of the header (for example, 4).
  • Header outer padding: Controls spacing outside the header area (between the header border and the top/bottom of the page).
    • Top spacing: Adjust the outer spacing above the header (for example, 20).
    • Bottom spacing: Adjust the outer spacing below the header (for example, 10).
  • Theme Settings: Access global theme settings related to the header section.
  • Custom CSS: Add custom CSS code to apply custom styling to the header section.
