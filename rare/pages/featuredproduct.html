Featured product

The Featured product section in the Rare theme allows you to showcase a single star product directly on any page. Customers can view product imagery, switch variants and swatches, read full descriptions, and complete purchases using direct Add to Cart or Dynamic Checkout buttons without leaving the page.

Featured product Section Settings

Customize section-wide settings such as the color scheme, product catalog selection, gallery media layout (slider or side-by-side), media sizing (contain or cover), and desktop/mobile spacing.

Steps

  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize to open the Theme Editor.
  • In the Template sidebar, select Featured product (or click Add section → Featured product).
  • Choose a Color scheme for the section background and text.
  • Click Select product and pick the product you want to feature.
  • Under Image gallery, configure the Media type (Slider or Side way) and Media size (Contain or Cover).
  • Adjust Desktop padding and Mobile padding as desired.
  • Click Save to apply your changes.
  • Color scheme: Select a predefined theme color scheme (e.g., Scheme 1, Scheme 2, etc.) to set background, surface, and text colors. Click Edit scheme to customize the scheme's colors.
  • Select product: Choose the product from your store catalog to display in this featured section.
  • Image gallery:
    • Media type: Select the gallery display layout:
      • Slider: Arranges product images in a swipeable horizontal carousel with pagination dots.
      • Side way: Arranges product images side-by-side or stacked for a rich lookbook presentation.
    • Media size: Select how product media scales inside the container:
      • Contain: Fits the entire image within the container frame without cropping.
      • Cover: Fills the entire media area, cropping edges if necessary for a full-bleed aesthetic.
  • Desktop padding:
    • Padding top: Adjust the top vertical spacing on desktop screens (in pixels, e.g., 40 px).
    • Padding bottom: Adjust the bottom vertical spacing on desktop screens (in pixels, e.g., 40 px).
  • Mobile padding:
    • Padding top: Adjust the top vertical spacing on mobile devices (in pixels, e.g., 40 px).
    • Padding bottom: Adjust the bottom vertical spacing on mobile devices (in pixels, e.g., 40 px).

Available Product Block

  • Inventory: Displays the product's real-time stock availability status and remaining quantity dynamically, updating automatically when different variants are selected.
  • Tags: Displays an eye-catching highlight badge or promotional tag (such as Customer Favourites, Trending, or Best Seller) directly above the product title.
    • Text: Enter the badge label text displayed inside the tag pill. Supports dynamic source connections.
    • Text color: Select the color for the badge label text (for example: #FFFFFF).
    • Text background: Select the fill background color for the badge pill (for example: #B6303A).
  • Title: Displays the name of the product prominently in the section.
    • Font size: Choose the semantic heading level and visual size for the product title (selectable from H1, H2, H3, H4, or H5).
  • Description: Shows the product's detailed narrative description and specifications.
    • Number of lines to show by default: Controls how many lines of description copy are visible initially before expanding.
  • Separator: Inserts a clean horizontal divider line between blocks for structured content organization.
  • Price: Displays the product's pricing details, compare-at regular price, discount percentage badge (e.g., SALE 12%), and tax/shipping calculation notes, updating automatically when variants change.
  • Variant: Allows customers to choose between different product options such as size, color, or material using buttons, swatches, or dropdown menus.
    • Options type: Select how product variants are displayed:
      • Dropdown: Displays variants in a compact dropdown list.
      • Button: Shows variants as clickable buttons or swatches.
    • Enable variant image on swatch: Toggle on to display variant thumbnail preview images directly inside color/variant swatches.
    • Option background: Select the background fill color for inactive variant buttons.
    • Option text: Select the text label color for inactive variant buttons.
    • Active option background: Select the background highlight color for the active variant button.
    • Active option text: Select the text color for the active variant button.
    • Opacity: Adjust the background opacity percentage for variant button containers.
    To know more about how to set up color swatches: Click here.
  • Size chart: Displays an interactive sizing guide button that opens a popup modal with sizing reference images, measurement tables, or content from a dedicated Shopify page.
    • Title: Enter the label text displayed on the size chart button (for example: Size chart). Supports dynamic source connections.
    • Size chart icon: Upload or select an optional custom icon image to display next to the button title.
    • Desktop image: Upload the primary size guide chart or measurement graphic displayed in the modal on desktop viewports.
    • Mobile image: Upload an optimized size chart graphic tailored for mobile screens.
    • Select page (OR): Alternatively, select a custom Shopify informational page to display rich text, sizing tables, or sizing guides directly inside the popup.
    • Link to a product option: Toggle on to restrict the size chart button visibility so it only appears when the product contains a matching variant option.
    • Product option name: Enter the variant option name required for the size chart to appear (for example: Size or Ring Size).
  • Quantity: Allows customers to choose the number of items they want to purchase directly on the section, making it easy to adjust quantities before adding products to the cart.
    • Background: Select the background fill color for the quantity input box.
    • Text color: Select the color for the numeric quantity count and +/- stepper buttons.
  • Buy now: Renders the primary call-to-action buttons (ADD TO CART and accelerated checkout BUY IT NOW) along with optional gift card recipient inputs.
    • Dynamic checkout button: Toggle on to display dynamic 1-click accelerated checkout buttons (such as Shop Pay, Apple Pay, Google Pay, or PayPal).
    • Gift card recipient form: Toggle on to show recipient fields (recipient email, name, optional message, and delivery date) when the featured item is a gift card product.
  • Share buttons: Displays social sharing icons (Facebook, Twitter/X, Pinterest, and Email), allowing customers to easily share the product with friends and on social media.
  • Collapsible tab: Displays collapsible accordion drawer rows that allow customers to expand and view additional product information, materials, or policies.
    • Heading: Enter the title label displayed on the collapsible accordion row. Supports dynamic source connections.
    • Content: Enter rich text copy, bullet points, or links to display inside the expanded accordion drawer. Supports dynamic source connections.
    • Default open: Toggle on to keep this collapsible tab open and expanded by default when the page loads.
  • Vendor: Displays the name of the product's brand or supplier on the product section.
  • SKU: Displays the product's unique Stock Keeping Unit (SKU) identifier, automatically updating when different variants are selected.
  • Text: Adds custom informational copy, badges, or announcements into the product details area. Supports dynamic source connections.
  • Payment icons: Displays accepted payment method logos (such as Visa, Mastercard, Amex, Apple Pay, Google Pay, and PayPal) to reassure shoppers during checkout.

FAQs

Where can I find the Featured product section?

From your Shopify admin, go to Online Store > Themes and click Customize. In the template sidebar, locate Featured product or click Add section > Featured product to add it to your page.

What is the difference between Slider and Side way media types?

Slider presents all product images inside a compact carousel that shoppers can slide through with swipe gestures or dots. Side way arranges product images side-by-side or stacked vertically for a lookbook-style presentation.

Can shoppers purchase variants directly from the Featured product section?

Yes. When the Variant and Buy now blocks are added, customers can select variant swatches, pick quantities, and click Add to Cart or accelerated checkout (Buy It Now) directly from the section.

How do I show the Size chart only for products with specific variant options?

Under Featured product in the Theme Editor, select the Size chart block. Toggle on Link to a product option and enter the option name (such as Size or Ring Size). The size guide button will only appear when that option exists on the featured product.
