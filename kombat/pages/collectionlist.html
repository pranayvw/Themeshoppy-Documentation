Theme documentation

Collection list

The Collection list section in the Kombat theme displays your collections as image cards in a slider, under a heading and description. Each card shows the collection image, title, and product count, and an optional countdown card can promote a limited-time offer.

Configure collection list Try the theme

Setup

Steps to Set Up the Collection List in Kombat

How to Configure the Collection List

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Template list, click Add section and select Collection list, or select the section if it is already on the page.
  • Adjust the section settings according to your preferences.
  • Click Add Collection to add a collection card, then choose the collection to display.
  • Click Save to apply your changes.

Collection List Section Settings

  • Color scheme: Choose a color scheme for the section. Use Edit scheme to customize the selected scheme.
  • Heading:
    • Heading: Enter the section heading (for example, Gaming Collectibles Hub). The text editor supports bold, italic, and links.
    • Highlight italic words: Select the words to highlight in the heading and press the italic (I) button. Those words are shown upright with the theme’s gradient.
    • Heading font size: Choose the size of the heading (for example, Small).
    • Heading alignment: Align the heading to the left, center, or right.
    • Description: Add supporting text below the heading. The text editor supports bold, italic, links, and bulleted or numbered lists.
    • Description width: Set the width of the description using the slider (for example, 450px).
  • Slider:
    • Collections per view on desktop: Set how many collection cards are visible at once on desktop (for example, 5).
    • Show arrows: Turn this option on to show navigation arrows on the slider.
  • Cards:
    • Image ratio: Choose the shape of the card images (for example, Square).
    • Show product count: Turn this option on to show the number of products on each card. It only shows on cards linked to a collection.
    • Card corner radius: Adjust the corner radius of the cards using the slider (for example, 18px).
  • Countdown:
    • Show countdown: Turn this option on to display the countdown card. When it is off, the collections use the full width.
    • Countdown heading: Enter the heading shown on the countdown card (for example, Level Up Your Loot Before These Gaming Deals Respawn).
    • End date: Enter the date the countdown ends, using the YYYY-MM-DD format (for example, 2026-12-31).
    • Countdown background image: Select or upload a background image for the countdown card.
    • Button label: Enter the text shown on the button (for example, Unleashed Offer Games).
    • Button link: Select the page, product, or collection that the button opens (for example, Deals).
    • Open link in new tab: Turn this option on to open the button link in a new browser tab.
    • Button style: Choose the button style, such as Gradient.
    • Show cart icon: Turn this option on to show a cart icon on the button.
    • Show arrow icon: Turn this option on to show an arrow icon on the button.
  • Edge shadows: Softly blend the top and bottom edges into the sections around this one. Pick the color scheme used by the section above or below.
    • Show top shadow: Turn this option on to display a shadow along the top edge.
    • Show bottom shadow: Turn this option on to display a shadow along the bottom edge.
    • Bottom shadow color scheme: Select the color scheme for the bottom shadow.
    • Bottom shadow height: Adjust the height of the bottom shadow (for example, 120px).
  • Desktop padding:
    • Padding top: Adjust the top spacing on desktop screens (for example, 80px).
    • Padding bottom: Adjust the bottom spacing on desktop screens (for example, 45px).
  • Mobile padding:
    • Padding top: Adjust the top spacing on mobile screens (for example, 35px).
    • Padding bottom: Adjust the bottom spacing on mobile screens.

Blocks

Collection Block Settings

Each Collection block is one card in the slider. Add as many cards as you need with Add Collection.

  • Collection: Choose the collection that the card displays.
  • Custom content: Use these options to replace the details taken from the collection.
    • Image: Select or upload an image to replace the collection image.
    • Title: Enter a title to replace the collection title.
    • Link: Paste a link or search for a page to replace the collection link.

Questions

Frequently asked questions

Select the Collection list section in the Theme Editor and click Add Collection. Then choose the collection to display in the Collection setting of the new block.

Open the Collection block and use the Custom content settings. The Image, Title, and Link you enter replace the collection’s own image, title, and link.

Turn on Show countdown, then enter the End date in the YYYY-MM-DD format. You can also set the countdown heading, background image, and button. When the countdown is off, the collections use the full width.

Make sure Show product count is turned on. The product count only shows on cards that are linked to a collection.
