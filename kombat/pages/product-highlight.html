Theme documentation

Product highlight

The Product highlight section in the Kombat theme features your products one at a time. A gallery of thumbnails and a large main image sit beside the product details: subheading, title, description, price, variant picker, quantity, and the Add to cart and Buy it now buttons. It can also show delivery information, key features, and a coupon with a Copy code button.

Setup

Steps to Set Up the Product Highlight in Kombat

How to Configure the Product Highlight

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Template list, click Add section and select Product highlight, or select the section if it is already on the page.
  • Adjust the section settings according to your preferences.
  • Click Add Product to add a product, then choose the product and its images.
  • Click Save to apply your changes.

Product Highlight Section Settings

  • Color scheme: Choose a color scheme for the section. Use Edit scheme to customize the selected scheme.
  • Gallery:
    • Thumbnail aspect ratio: Choose the shape of the gallery thumbnails (for example, Landscape (16:10)).
    • Main image aspect ratio: Choose the shape of the main image frame (for example, Portrait (3:4)). Images are shown in full inside this frame.
  • Product details:
    • Show variant picker: Turn this option on to show the product’s variant options.
    • Show selected variant image: Turn this option on to show the variant image next to the variant options when the selected variant has its own image.
    • Show dynamic checkout button: Turn this option on to show the customer’s preferred payment method, such as PayPal or Apple Pay, as a Buy now button.
    • Show View full details link: Turn this option on to show a link to the full product page.
    • Add to cart button style: Choose the style of the Add to cart button (for example, Gradient).
    • Show cart icon: Turn this option on to show a cart icon on the Add to cart button.
    • Show arrow icon: Turn this option on to show an arrow icon on the Add to cart button.
    • Variant options type: Choose how the variant options are displayed (for example, Mixed).
    • Show variant image on color swatches: Turn this option on to show the variant image instead of the swatch color. It applies to options named Color and any names added in Theme settings → Swatches → Extra swatch option names.
    • Show delivery information: Turn this option on to show a delivery block below the buttons.
    • Delivery heading: Enter the heading of the delivery block (for example, Delivery).
    • Delivery text: Enter the delivery text. The text editor supports bold, italic, links, and bulleted or numbered lists.
  • Coupon:
    • Show coupon: Turn this option on to show a coupon below the product details. Create the discount code in your Shopify admin under Discounts.
    • Coupon color scheme: Choose a color scheme for the coupon.
    • Background image: Select or upload a background image for the coupon.
    • Image: Select or upload an image shown before the heading, in front of the background. A transparent PNG works best.
    • Background image overlay: Set how much the background image is darkened or lightened with the color scheme background, so the text stays readable (for example, 15%).
    • Heading: Enter the coupon heading (for example, 10% off).
    • Text: Enter the coupon text (for example, On your first order).
    • Discount code: Enter the discount code shown on the coupon (for example, WELCOME10).
  • Edge shadows: Softly blend the top and bottom edges into the sections around this one. Pick the color scheme used by the section above or below.
    • Show top shadow: Turn this option on to display a shadow along the top edge.
    • Top shadow color scheme: Choose the color scheme used for the top shadow.
    • Top shadow height: Set the height of the top shadow using the slider (for example, 180px).
    • Show bottom shadow: Turn this option on to display a shadow along the bottom edge.
    • Bottom shadow color scheme: Choose the color scheme used for the bottom shadow.
    • Bottom shadow height: Set the height of the bottom shadow using the slider (for example, 120px).
  • Section padding:
    • Top padding: Adjust the top spacing on desktop screens (for example, 48px).
    • Bottom padding: Adjust the bottom spacing on desktop screens (for example, 48px).
    • Top padding on mobile: Adjust the top spacing on mobile screens (for example, 32px).
    • Bottom padding on mobile: Adjust the bottom spacing on mobile screens (for example, 32px).

Blocks

Product Block Settings

Each Product block is one product in the section. Add as many products as you need with Add Product. The title, price, stock status, and variants come from the product itself.

  • Product: Choose the product to feature.
  • Thumbnail image: Select or upload the image shown for this product in the gallery.
  • Main image: Select or upload the large image shown for this product.
  • Subheading icon: Select or upload a small icon shown before the subheading.
  • Subheading: Enter the text shown above the product title (for example, Playstation).
  • Description: Enter the text shown below the product title. The text editor supports bold, italic, links, and bulleted or numbered lists.
  • Heading: Enter a heading for the second text (for example, Key Features).
  • Description: Enter the text shown below that heading. The text editor supports bold, italic, links, and bulleted or numbered lists.

Frequently asked questions

Select the Product highlight section in the Theme Editor and click Add Product. Choose the Product, then add a Thumbnail image and a Main image.

Use Thumbnail aspect ratio and Main image aspect ratio under Gallery in the section settings. Images are shown in full inside the frame.

Turn Show coupon and Show delivery information on or off in the section settings. The discount code itself must be created in your Shopify admin under Discounts.

Under Product details, choose the Add to cart button style, turn Show cart icon and Show arrow icon on or off, and use Show dynamic checkout button to show or hide the Buy now button.
