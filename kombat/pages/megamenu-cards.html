Mega menu cards

The Mega Menu Cards block in the Kombat theme creates a wide dropdown menu made of image cards. Each second-level menu item becomes a card with its own image, title, and list of third-level links, and an optional promo card can highlight a collection, product, or special offer.

Configure mega menu Try the theme

Setup

Steps to Set Up the Mega Menu Cards in Kombat

How to Configure the Mega Menu Cards

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Header section, click Add block and select Mega menu cards.
  • Adjust the settings according to your preferences.
  • Click Save to apply your changes.

Configure the Mega Menu Cards

  • Mega menu target: Enter the name of the top-level navigation menu item that should open this mega menu, in lowercase with spaces replaced by hyphens (for example, build-your-setup; Shop all becomes shop-all). It must match the menu item in your Shopify navigation.
  • Menu structure: The second-level links in the navigation menu become the cards, and their third-level links are listed inside each card. Organize your nested menu links in Shopify to control the content and order of the cards.
  • Color scheme: Select a color scheme for the mega menu cards. Use Edit scheme to customize the selected scheme.
  • Show background glow: Enable this option to add a glow effect behind the mega menu.
  • Glow color: Choose a custom color for the glow. Leave it empty to use the color scheme’s highlight color.
  • Heading: Enter a heading to show above the cards. Leave it empty to hide it.

Card Images

Use these options to control the image displayed on each card.

  • Show card images: Enable this option to display an image on each card.
  • Image aspect ratio: Choose the aspect ratio of the card images, such as Landscape (4:3).
  • Image metaobject type: Enter the metaobject definition type used to store the card images (for example, menu_image). Give each second-level menu item a metaobject entry whose handle is the item name in lowercase, with spaces and / replaced by - (for example, Tops / T-Shirts becomes tops-t-shirts), and add an image field (file).
  • Image field key: Enter the key of the image field in the metaobject definition (for example, image). A field named Second level menu has the key second_level_menu.
  • Use collection and product images: Enable this option for cards that link to a collection or product and have no metaobject image.

Promo Card Settings

The promo card lets you highlight a collection, a product, or a special offer inside the mega menu.

  • Show promo card: Enable this option to display the promo card.
  • Image: Select or upload an image to display in the promo card.
  • Title: Enter the title shown on the promo card (for example, Upgrade Your Gaming Setup).
  • Button label: Enter the text to display on the button (for example, Explore more).
  • Button link: Select the destination page, product, or collection that the button should link to.
  • Open button link in new tab: Enable this option to open the button link in a new browser tab.
  • Button style: Choose the visual style of the button, such as Secondary.

Questions

Frequently asked questions

Check that the Mega menu target matches the name of the intended top-level menu item (for example, build-your-setup), in lowercase with spaces replaced by hyphens. Also make sure the navigation links are nested correctly beneath that parent item.

Menu items and links are managed in Shopify Admin → Content → Menus. The second-level links become the cards, while their third-level links are listed inside each card. The theme editor controls the target, color scheme, glow, card images, and promo card.

Make sure Show card images is enabled and that the Image metaobject type and Image field key match your metaobject definition. Each second-level menu item needs a metaobject entry whose handle matches its name. For cards that link to a collection or product, you can enable Use collection and product images.
