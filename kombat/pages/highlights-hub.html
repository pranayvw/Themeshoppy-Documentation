Theme documentation

Highlights hub

The Highlights hub section in the Kombat theme brings two tabs together in one place, such as Events and Insights. Visitors switch between the tabs to browse event cards and blog articles in a carousel of cards that glow on hover.

Configure highlights hub Try the theme

Setup

Steps to Set Up the Highlights Hub in Kombat

How to Configure the Highlights Hub

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Template list, click Add section and select Highlights hub, or select the section if it is already on the page.
  • Adjust the section settings according to your preferences.
  • Click Add block to add an Event or a Blog tab, then configure it.
  • Click Save to apply your changes.

Highlights Hub Section Settings

  • Color scheme: Choose a color scheme for the section. Use Edit scheme to customize the selected scheme.
  • Background image: Select or upload a background image for the section.
  • Heading:
    • Highlight italic words: Select the words to highlight in the heading and press the italic (I) button. Those words are shown upright with the theme’s gradient.
    • Heading font size: Choose the size of the heading (for example, Medium).
    • Description width: Set the width of the description using the slider (for example, 490px).
  • Events tab: Shows the Event blocks.
    • Tab label: Enter the name shown on the tab button (for example, Events).
    • Heading: Enter the heading shown when this tab is selected (for example, Your Gaming Hub). The text editor supports bold, italic, and links.
    • Description: Add supporting text below the heading. The text editor supports bold, italic, links, and bulleted or numbered lists.
  • Blog tab: Shows the Blog tab blocks.
    • Tab label: Enter the name shown on the tab button (for example, Insights).
    • Heading: Enter the heading shown when this tab is selected (for example, Gaming Insights Hub). The text editor supports bold, italic, and links.
    • Description: Add supporting text below the heading. The text editor supports bold, italic, links, and bulleted or numbered lists.
    • Articles per tab: Set how many articles are shown in each tab (for example, 6).
    • Card aspect ratio: Choose the shape of the article cards (for example, Portrait). Adapt to image uses the first article’s image in each tab.
    • Card glow color: Choose the color of the shadow shown around a card on hover (for example, #D852A4).
    • Show tags: Turn this option on to show up to 3 tags per article.
    • Show excerpt: Turn this option on to show the article excerpt.
    • Show author: Turn this option on to show the article author.
    • Show date: Turn this option on to show the article date.
  • Edge shadows: Softly blend the top and bottom edges into the sections around this one. Pick the color scheme used by the section above or below.
    • Show top shadow: Turn this option on to display a shadow along the top edge.
    • Show bottom shadow: Turn this option on to display a shadow along the bottom edge.
  • Desktop padding:
    • Padding top: Adjust the top spacing on desktop screens (for example, 70px).
    • Padding bottom: Adjust the bottom spacing on desktop screens (for example, 70px).
  • Mobile padding:
    • Padding top: Adjust the top spacing on mobile screens (for example, 40px).
    • Padding bottom: Adjust the bottom spacing on mobile screens (for example, 40px).

Blocks

Event Block Settings

Each Event block is one event card in the Events tab. Add as many events as you need with Add block.

  • Image: Select or upload the image shown on the event card.
  • Title: Enter the event title (for example, Indie Game Showcase).
  • Description: Enter a short description of the event.
  • Date: Enter the event date (for example, Dec 12, 2026).
  • Location: Enter where the event takes place (for example, Pixel Hall, Seattle).
  • Button label: Enter the text shown on the button (for example, Contact Now).
  • Button link: Select the page that the button opens (for example, Contact).
  • Button style: Choose the button style, such as Secondary.
  • Show cart icon: Turn this option on to show a cart icon on the button.
  • Show arrow icon: Turn this option on to show an arrow icon on the button.

Blocks

Blog Tab Block Settings

Each Blog tab block adds one tab under the heading and description of the Blog tab. When a visitor selects it, the articles of the blog you chose are shown as cards. Add as many tabs as you need with Add block.

  • Tab label: Enter the name shown on the tab (for example, VR & Technologies).
  • Blog: Choose the blog whose articles are shown when the tab is selected (for example, VR Technologies).

How many articles are shown, and what each card displays, is controlled by the Blog tab settings in the section settings above.

Questions

Frequently asked questions

Select the Highlights hub section in the Theme Editor and click Add block, then choose Event. Set the image, title, description, date, location, and button of the new block.

Use the Tab label setting under Events tab and Blog tab in the section settings (for example, Events and Insights).

In the Blog tab settings, turn Show tags (up to 3 tags per article), Show excerpt, Show author, and Show date on or off.

Adapt to image uses the first article’s image in each tab to set the shape of the cards. Choose another Card aspect ratio, such as Portrait, to use a fixed shape.
