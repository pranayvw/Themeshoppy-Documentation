Mega menu showcase

The Mega Menu Showcase in the Kombat theme creates a wide, visual dropdown menu that helps customers explore gaming categories, popular games, and gaming platforms. It can also feature a promotional image and call-to-action button to highlight new releases and pre-order offers.

Configure mega menu Try the theme

Setup

Steps to Set Up the Mega Menu Showcase in Kombat

How to Configure the Mega Menu

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Header section, click Add block and select Mega menu showcase.
  • Adjust the settings according to your preferences.
  • Click Save to apply your changes.

Configure the Mega Menu Showcase

  • Mega menu target: Enter the handle of the top-level navigation menu item that should open this mega menu. Use lowercase letters and replace spaces with hyphens (for example, discover-games). The handle must match the menu item in your Shopify navigation.
  • Menu structure: The second-level links in the navigation menu become the column headings, and their third-level links appear as the items within each column. Organize your nested menu links in Shopify to control the content and order of these columns.
  • Color scheme: Select a color scheme for the mega menu showcase. Use Edit scheme to customize the selected scheme's background and text colors.

Background Glow and Item Icons

Use these options to add a visual glow effect to the dropdown and display icons beside third-level menu items.

  • Show background glow: Enable this option to add a glow effect behind the mega menu showcase.
  • Glow color: Choose a custom color for the background glow. Leave the field empty to use the highlight color from the selected color scheme.
  • Icon metaobject type: Enter the metaobject definition type used to store menu item icons. The setting shown in the theme editor uses menu_icon.
  • Icon image field key: Enter the key of the image field in the icon metaobject definition. The setting shown in the theme editor uses icon. A field named third_level_menu has the key third_level_menu.

Promo Card Settings

The Promo Card allows you to highlight featured games, upcoming releases, and special offers within the mega menu. You can customize its image, badge, and button to direct customers to specific products or collections.

  • Image: Select or upload an image to display in the promotional card.
  • Image aspect ratio: Choose the aspect ratio for the promotional image, such as Landscape (16:10).
  • Image link: Set a destination link for the promotional image.
  • Badge text: Enter the text to display in a badge at the top-left corner of the image (for example, 19 Nov 2026).
  • Badge icon: Select an icon to display alongside the badge text (for example, Calendar).
  • Button label: Enter the text to display on the promotional button (for example, Pre Order Now).
  • Button link: Select the destination page, product, or collection that the button should link to.
  • Open button link in new tab: Enable this option to open the button link in a new browser tab.
  • Button style: Choose the visual style of the promotional button, such as Gradient.
  • Show arrow on button: Enable this option to display an arrow icon alongside the button label.

Questions

Frequently asked questions

Check that the Mega menu target matches the handle of the intended top-level menu item (for example, discover-games). Also make sure the navigation links are nested correctly beneath that parent item.

Menu items and links are managed in Shopify Admin → Content → Menus. The second-level links form the column headings, while third-level links appear as menu items. The theme editor controls the target, color scheme, background glow, and icon metaobject settings.
