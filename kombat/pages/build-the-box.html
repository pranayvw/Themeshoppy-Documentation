Theme documentation

Build the box

The Build the box section in the Kombat theme lets customers put together their own bundle. They browse your products in a slider, preview each one, add it to the bundle, and add the whole bundle to the cart. A bundle panel keeps count of the items chosen, shows the bundle total, and can end with an image or a video.

Setup

Steps to Set Up Build the Box in Kombat

How to Configure Build the Box

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Template list, click Add section and select Build the box, or select the section if it is already on the page.
  • Adjust the section settings according to your preferences.
  • Click Add Product to add a product to the slider, then choose the product to display.
  • Click Save to apply your changes.

Build the Box Section Settings

  • Color scheme: Choose a color scheme for the section. Use Edit scheme to customize the selected scheme.
  • Glow color: Pick the color used for the panel outlines, the active product, and the bundle progress bar.
  • Heading:
    • Heading: Enter the section heading. The text editor supports bold, italic, and links.
    • Highlight italic words: Select the words to highlight in the heading and press the italic (I) button. Those words are shown upright with the theme’s gradient.
    • Heading font size: Choose the size of the heading (for example, Small).
    • Heading alignment: Align the heading to the left, center, or right.
    • Description: Add supporting text below the heading. The text editor supports bold, italic, links, and bulleted or numbered lists.
    • Description width: Set the width of the description using the slider (for example, 720px).
  • Bundle:
    • Bundle heading: Enter the heading shown on the bundle panel (for example, Complete Your Setup).
    • Maximum bundle items: Set the maximum number of items a customer can add to the bundle, using the slider (for example, 6). Every unit is counted, so two of the same product count as two items.
    • Bundle panel image: Select or upload an image shown at the bottom of the bundle panel.
    • Bundle panel video: Select or upload a video for the bottom of the bundle panel.
  • Product slider:
    • Products per view on desktop: Set how many product cards are visible at once in the slider on desktop, using the slider (for example, 3).
  • Product preview:
    • Show product description: Turn this option on to show the product description in the preview.
    • Show product image thumbnails: Turn this option on to show thumbnails of the product images below the preview.
    • Variant options type: Choose how the variant options are displayed in the preview (for example, Mixed).
    • Show variant image on color swatches: Turn this option on to show the variant image instead of the swatch color. It applies to options named Color and any names added in Theme settings → Swatches → Extra swatch option names.
  • Buttons:
    • Add to bundle button style: Choose the style of the Add to Bundle button: Primary or Secondary.
    • Add bundle to cart button style: Choose the style of the button that adds the bundle to the cart: Primary or Secondary.
  • Edge shadows: Softly blend the top and bottom edges into the sections around this one. Pick the color scheme used by the section above or below.
    • Show top shadow: Turn this option on to display a shadow along the top edge.
    • Show bottom shadow: Turn this option on to display a shadow along the bottom edge.
  • Desktop padding:
    • Padding top: Adjust the top spacing on desktop screens (for example, 50px).
    • Padding bottom: Adjust the bottom spacing on desktop screens (for example, 70px).
  • Mobile padding:
    • Padding top: Adjust the top spacing on mobile screens (for example, 40px).
    • Padding bottom: Adjust the bottom spacing on mobile screens.

Blocks

Product Block Settings

Each Product block is one product in the slider. Add as many products as you need with Add Product.

  • Product: Choose the product that the card and the preview display.
  • Card label: Enter a label shown on the product card instead of the product title.
  • Short description: Enter a short description shown in the preview instead of the product description.
  • Preview image: Select or upload an image shown as the main image in the product preview instead of the product image.
  • Slider image: Select or upload an image shown on the product card in the slider instead of the product image.
