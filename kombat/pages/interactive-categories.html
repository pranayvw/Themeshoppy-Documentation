Theme documentation

Interactive categories

The Interactive categories section in the Kombat theme is a full-width banner where visitors choose a category, such as Open World, Action, Racing, or Sci-Fi, to see that category’s products as cards below the heading. A selected product can play a background video or show an image, and short icon-and-text features sit below the category pills.

Configure interactive categories Try the theme

Setup

Steps to Set Up Interactive Categories in Kombat

How to Configure Interactive Categories

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Template list, click Add section and select Interactive categories, or select the section if it is already on the page.
  • Adjust the section settings according to your preferences.
  • Click Add Category to add a category, then add its products, background videos, and features.
  • Click Save to apply your changes.

Interactive Categories Section Settings

  • Color scheme: Choose a color scheme for the section. Use Edit scheme to customize the selected scheme.
  • Heading:
    • Heading: Enter the section heading (for example, Enter The Game). The text editor supports bold, italic, and links.
    • Highlight italic words: Select the words to highlight in the heading and press the italic (I) button. Those words are shown upright with the theme’s gradient.
    • Heading font size: Choose the size of the heading (for example, Large).
    • Description: Add supporting text below the heading. The text editor supports bold, italic, links, and bulleted or numbered lists.
  • Section layout:
    • Section height: Choose the height of the section on desktop (for example, Large).
    • Mobile section height: Choose the height of the section on mobile devices (for example, Match desktop setting).
    • Image overlay opacity: Adjust how strong the overlay over the background image or video is, using the slider (for example, 15%).
    • Category transition: Choose the animation used when the category changes (for example, Neon blade sweep).
  • Products:
    • Products heading: Enter the heading shown above the product cards (for example, More in [category]). Use [category] to insert the category label.
    • View all link text: Enter the text of the link shown next to the products heading (for example, View all). It is shown when a category has a link.
    • Cards visible on desktop: Set how many product cards are visible at once on desktop (for example, 5). More products scroll sideways.
    • Card hover glow: Choose the glow color shown when a visitor hovers over a card (for example, #D852A4).
  • Edge shadows: Softly blend the top and bottom edges into the sections around this one. Pick the color scheme used by the section above or below.
    • Show top shadow: Turn this option on to display a shadow along the top edge.
    • Top shadow color scheme: Select the color scheme for the top shadow.
    • Top shadow height: Adjust the height of the top shadow (for example, 180px).
    • Show bottom shadow: Turn this option on to display a shadow along the bottom edge.
    • Bottom shadow color scheme: Select the color scheme for the bottom shadow.
    • Bottom shadow height: Adjust the height of the bottom shadow (for example, 120px).

Blocks

Category Block Settings

Each Category block is one category in the section. Add categories with Add Category. The button is disabled when the limit is reached, and it shows how many categories you have used (for example, 4/4).

  • Label: Enter the category name shown on the pill (for example, Open World).
  • Background image: Select or upload an image to replace the category pill image. It is shown when the category is selected.
  • Link: Add a link to the category pill. When a visitor clicks the pill, they are taken to this link.

Products

Each category has a list of products. Every product in the list has the same settings.

  • Product: Choose the product shown on the card.
  • Product image: Select or upload an image to replace the product image on the card. If no video is selected, this image shows in the background when the product is selected.
  • Background video: Select or upload a video that plays in the background when the product is selected.

Features

Short icon and text items shown below the category pills. Each feature has the same settings.

  • Icon: Select or upload the icon shown beside the feature text.
  • Text: Enter the feature text (for example, Immersive Worlds, Cinematic Experience, or For Every Playstyle).

Frequently asked questions
