Theme documentation

Footer section

The Footer is an important part of your store layout as it appears on every page and provides customers with quick access to essential information and navigation links. With the Kombat theme, the footer is designed to be flexible and visually organized, allowing you to display menus, policies, newsletter signup, and important store details in a structured layout.

The footer helps improve the user experience by making it easier for customers to find information such as policies, contact details, and additional navigation links. It also supports branding elements like logos and social media icons, helping you maintain a consistent brand identity across your store.

Setup

Steps to Set Up the Footer Section in Your Shopify Theme, Kombat

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Theme Editor, scroll down and select the Footer section from the left sidebar.
  • Adjust the settings, blocks, and layout options according to your preferences.
  • Click Save to apply your changes.

Follow these steps to configure your Footer section

  • Color scheme: Choose a color scheme to control the background and text colors of the footer section. Use Edit scheme to customize the selected scheme.
  • Section border radius: Adjust the corner radius of the footer section using the slider (for example, 0px).
  • Background image: Select or upload an image to display as the footer background.
  • Enable overlay: Turn this option on to add a color overlay over the background image.
    • Overlay opacity: Adjust how strong the overlay appears (for example, 70%).
  • Glow:
    • Show glow: Turn this option on to add a glow effect to the footer.
    • Glow color: Choose the color of the glow (for example, #D852A4).
    • Glow opacity: Adjust the opacity of the glow (for example, 70%).
  • Side images:
    • Show side images: Turn this option on to display the side images. Add Side image blocks to fill the columns. The left column scrolls down and the right column scrolls up.
    • Scroll time per image: Set how many seconds each image takes to scroll (for example, 5s).
  • Social media:
    • Show social icons: Turn this option on to display your social media icons. Add your social links in Theme settings → Social media.
    • Icon background color: Choose the background color of the icons (for example, #222235).
    • Icon color: Choose the color of the icons (for example, #FFFFFF).
    • Icon border radius: Adjust the corner radius of the icons (for example, 10px).
  • Follow on Shop:
    • Show Follow on Shop button: Lets customers follow your store on the Shop app. Shop Pay must be turned on.
  • Footer bottom:
    • Color scheme: Select a color scheme for the footer bottom bar.
    • Bottom bar position: Choose whether the bottom bar appears at the Top or Bottom.
  • Localization:
    • Enable country selector: Turn this option on to show a country/region selector in the footer.
    • Enable language selector: Turn this option on to show a language selector in the footer.
  • Policies:
    • Show policies: Turn this option on to display your store policy links in the footer.
  • Newsletter:
    • Show newsletter signup: Turn this option on to display the newsletter signup form.
    • Heading: Enter a heading for the newsletter section (for example: Subscribe to our newsletter).
    • Text: Add a short message encouraging visitors to subscribe (for example: Be the first to hear about new arrivals, exclusive offers and events.).
    • Button label: Enter the text for the signup button.
    • Button style: Choose the button style, Primary or Secondary.
  • Desktop padding:
    • Padding top: Adjust the top spacing on desktop screens (for example, 20px).
    • Padding bottom: Adjust the bottom spacing on desktop screens (for example, 15px).
  • Mobile padding:
    • Padding top: Adjust the top spacing on mobile screens (for example, 40px).
    • Padding bottom: Adjust the bottom spacing on mobile screens (for example, 20px).

Available Blocks in Footer

  • Brand information Block: The Brand information block displays your logo and a short brand description in the footer, with an option to show payment icons.
    Brand information Block Configuration
    • Logo: Upload the logo to display in the footer.
    • Image ratio: Choose how the logo image fits, such as Adapt to image.
    • Logo width: Adjust the width of the logo using the slider (for example, 100%).
    • Description: Add a short rich text description about your brand.
    • Show payment icons: Turn this option on to display accepted payment method icons.
  • Menu Block: The Menu block displays a list of navigation links in the footer. You can add multiple menu blocks to organize different link groups such as Platform, Accessories, Community, or Support.
    Menu Block Configuration
    • Heading: Enter a title for the menu block (for example: Platform).
    • Select menu: Choose a navigation menu created in your Shopify admin (for example, Shop).
    • Block width: Adjust the width of the menu block using the slider (for example, 25).
  • Side image Block: The Side image block adds an image to the side columns of the footer. Add several Side image blocks to fill the columns when Show side images is turned on.
    Side image Block Configuration
    • Image: Select or upload the image to display.
    • Link: Add a link (for example, a collection) that opens when the image is clicked.
    • Column: Choose whether the image appears in the Left or Right column.

Questions

Frequently asked questions

Footer menu links are managed in your Shopify admin under Content → Menus. You can add or edit your menu items there, and then choose which menu to display in the Menu block inside your Footer section in the Theme Editor.

To display social media icons, go to Theme settings → Social media and add your social profile links. Then turn on Show social icons in the Footer section settings.

Turn on Show side images in the Footer section and add Side image blocks. Use the Column setting on each block to place it in the left or right column.

Turn on Show newsletter signup in the Footer section settings. You can then edit the heading, text, button label, and button style.
