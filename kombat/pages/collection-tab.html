Theme documentation

Collection tab

The Collection tab section in the Kombat theme lets customers switch between collections using icon tabs. Each tab shows the products of one collection as product cards, in a grid or a slider, under a heading and description.

Configure collection tab Try the theme

Setup

Steps to Set Up the Collection Tab in Kombat

How to Configure the Collection Tab

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Template list, click Add section and select Collection tab, or select the section if it is already on the page.
  • Adjust the section settings according to your preferences.
  • Click Add Tab to add a tab, then choose the collection whose products the tab displays.
  • Click Save to apply your changes.

Collection Tab Section Settings

  • Color scheme: Choose a color scheme for the section. Use Edit scheme to customize the selected scheme.
  • Heading:
    • Heading: Enter the section heading (for example, Editor’s Choice Collection). The text editor supports bold, italic, and links.
    • Highlight italic words: Select the words to highlight in the heading and press the italic (I) button. Those words are shown upright with the theme’s gradient.
    • Heading font size: Choose the size of the heading (for example, Small).
    • Heading alignment: Align the heading to the left, center, or right.
    • Description: Add supporting text below the heading. The text editor supports bold, italic, links, and bulleted or numbered lists.
    • Description width: Set the width of the description using the slider (for example, 450px).
  • Products:
    • Layout: Choose how the products of the active tab are arranged: Grid or Slider.
    • Maximum products to show: Set the maximum number of products shown for each tab using the slider (for example, 8).
  • Product card:
    • Card style: Choose the style of the product cards (for example, Expanding panel).
    • Image ratio: Choose the shape of the product images (for example, Square).
    • Show second image on hover: Turn this option on to show the product’s second image when a customer hovers over the card.
    • Show vendor: Turn this option on to show the product vendor on the card.
    • Show sale and sold out badges: Turn this option on to show badges, such as the discount percentage, on products that are on sale or sold out.
    • Show stock status: Turn this option on to show the stock status on the card (for example, Only 5 left).
    • Show description: Turn this option on to show the product description on the card.
    • Description lines: Set how many lines of the product description are shown, using the slider (for example, 2).
    • Show color swatch: Turn this option on to show the product’s color swatches on the card.
    • Show variant image on color swatches: Turn this option on to show the variant image instead of the swatch color. It applies to options named Color and any names added in Theme settings → Swatches → Extra swatch option names.
    • Show quick add: Turn this option on to show a quick add button on the card.
    • Quick add button style: Choose the style of the quick add button: Primary or Secondary.
    • Show view all button: Turn this option on to show a View all button below the products.
  • Mobile layout:
    • Products per row on mobile: Choose how many products are shown per row on mobile screens: 1 column or 2 columns.
  • Edge shadows: Softly blend the top and bottom edges into the sections around this one. Pick the color scheme used by the section above or below.
    • Show top shadow: Turn this option on to display a shadow along the top edge.
    • Show bottom shadow: Turn this option on to display a shadow along the bottom edge.
  • Desktop padding:
    • Padding top: Adjust the top spacing on desktop screens (for example, 50px).
    • Padding bottom: Adjust the bottom spacing on desktop screens (for example, 70px).
  • Mobile padding:
    • Padding top: Adjust the top spacing on mobile screens (for example, 40px).
    • Padding bottom: Adjust the bottom spacing on mobile screens (for example, 40px).

Blocks

Tab Block Settings

Each Tab block is one tab above the products. Add as many tabs as you need with Add Tab. The first tab is shown when the page loads, and customers click a tab to see the products of its collection.

  • Tab icon: Select or upload the image shown on the tab.
  • Accessible label: Enter the name of the tab (for example, Xbox). It is shown below the tab icon and is also read out by screen readers.
  • Collection: Choose the collection whose products are shown when the tab is selected.

Questions

Frequently asked questions

Select the Collection tab section in the Theme Editor and click Add Tab. Then choose the collection in the Collection setting of the new block, and add a Tab icon and an Accessible label.

Open the Tab block. Use Tab icon to change the image, and Accessible label to change the name shown below it.

Use Maximum products to show in the Products settings. It applies to every tab. To show the products in a slider instead of a grid, change Layout to Slider.

Make sure Show quick add and Show stock status are turned on in the Product card settings.
