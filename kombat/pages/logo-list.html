Theme documentation

Logo list

The Logo list section in the Kombat theme shows the brands you stock or partner with as a row of logos that scrolls continuously, next to a heading and a short text. You can set the speed and direction of the scroll, and pause it when a visitor hovers over the logos.

Configure logo list Try the theme

Setup

Steps to Set Up the Logo List in Kombat

How to Configure the Logo List

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Template list, click Add section and select Logo list, or select the section if it is already on the page.
  • Adjust the section settings according to your preferences.
  • Click Add block to add a Heading, a Text, or a Logo, then configure it.
  • Click Save to apply your changes.

Logo List Section Settings

  • Color scheme: Choose a color scheme for the section. Use Edit scheme to customize the selected scheme.
  • Text alignment: Align the heading and text to the left, center, or right on desktop.
  • Text alignment on mobile: Align the heading and text to the left, center, or right on mobile screens.
  • Logo marquee:
    • Seconds per logo: Set how long each logo takes to scroll past, using the slider (for example, 3 seconds). A higher value makes the scroll slower.
    • Direction: Choose the direction the logos scroll: Left or Right.
    • Pause on hover: Turn this option on to pause the scrolling while a visitor hovers over the logos.
  • Edge shadows: Softly blend the top and bottom edges into the sections around this one. Pick the color scheme used by the section above or below.
    • Show top shadow: Turn this option on to display a shadow along the top edge.
    • Show bottom shadow: Turn this option on to display a shadow along the bottom edge.
  • Desktop padding:
    • Padding top: Adjust the top spacing on desktop screens (for example, 60px).
    • Padding bottom: Adjust the bottom spacing on desktop screens (for example, 60px).
  • Mobile padding:
    • Padding top: Adjust the top spacing on mobile screens.
    • Padding bottom: Adjust the bottom spacing on mobile screens.

Blocks

Heading Block Settings

The Heading block adds the heading shown next to the logos. Add it with Add block.

  • Heading: Enter the heading text (for example, Explore Leading Gaming Brands). The text editor supports bold, italic, and links.
  • Highlight italic words: Select the words to highlight in the heading and press the italic (I) button. Those words are shown upright with the theme’s gradient.
  • Font size: Choose the size of the heading (for example, Small).

Blocks

Text Block Settings

The Text block adds a short text below the heading. Add it with Add block.

  • Text: Enter the text (for example, Discover games, consoles, and accessories from some of the most recognized names in gaming.). The text editor supports bold, italic, links, and bulleted or numbered lists.

Blocks

Logo Block Settings

Each Logo block is one brand logo in the scrolling row. Add as many logos as you need with Add block.

  • Logo image: Select or upload the logo image.
  • Brand name: Enter the brand name (for example, Sony). It is used as the alt text and as a fallback label if no image is uploaded.
  • Link: Paste a link or search for a page. This is optional, and it makes the logo clickable.
