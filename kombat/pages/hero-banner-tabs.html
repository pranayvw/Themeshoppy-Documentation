Hero banner tabs

The Hero banner tabs section in the Kombat theme creates a full-screen hero banner made of slides. Each slide can combine a large image or video with a subheading, heading, description, badges, and buttons, while a row of tab cards below the banner lets visitors switch between slides.

Configure hero banner tabs Try the theme

Setup

Steps to Set Up the Hero Banner Tabs in Kombat

How to Configure the Hero Banner Tabs

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Template list, click Add section and select Hero banner tabs, or select the section if it is already on the page.
  • Adjust the section settings according to your preferences.
  • Click Add Slide to add a slide, then configure each slide.
  • Click Save to apply your changes.

Hero Banner Tabs Section Settings

  • Section height: Choose the height of the section on desktop (for example, Full screen).
  • Mobile section height: Choose the height of the section on mobile devices (for example, Medium).
  • Tab card corner radius: Adjust the corner radius of the tab cards using the slider (for example, 14px).
  • Subheading text gradient: Choose the gradient style applied to the subheading text (for example, Linear gradient).
  • Change slide on tab hover: Turn this option on to switch to a slide when a visitor hovers over its tab.
  • Slide reveal style: Choose the animation used when a slide is revealed (for example, Neon blade sweep).
  • Edge shadows: Softly blend the top and bottom edges into the sections around this one. Pick the color scheme used by the section above or below.
    • Show top shadow: Turn this option on to display a shadow along the top edge.
    • Top shadow color scheme: Select the color scheme for the top shadow.
    • Top shadow height: Adjust the height of the top shadow (for example, 180px).
    • Show bottom shadow: Turn this option on to display a shadow along the bottom edge.
    • Bottom shadow color scheme: Select the color scheme for the bottom shadow.
    • Bottom shadow height: Adjust the height of the bottom shadow (for example, 120px).

Blocks

Slide Block Settings

Each Slide block is one slide of the banner. Add as many slides as you need with Add Slide.

Color Scheme and Media

  • Color scheme: Choose a color scheme for the slide. Use Edit scheme to customize the selected scheme.
  • Image: Select or upload the main image for the slide.
  • Mobile image: Select or upload a separate image to use on mobile devices.
  • Video: Select a video to use in the slide.
  • Thumbnail image: Select or upload the image shown on the slide’s tab card.

Layout and Side Shadow

  • Content alignment: Align the slide content to the Left, Center, or Right.
  • Content max width: Set the maximum width of the content area using the slider (for example, 440px).
  • Show side shadow: Darkens one side of the image so the text stays easy to read.
    • Shadow position: Choose whether the shadow appears on the Left or Right.
    • Shadow strength: Adjust how dark the shadow is (for example, 90%).
    • Shadow width: Adjust how far the shadow spreads across the image (for example, 75%).

Text and Heading

  • Subheading: Enter the short line shown above the heading (for example, Featured Release).
  • Show line after subheading: Turn this option on to display a line after the subheading.
  • Heading line: Each heading line starts on a new line. Add a heading line for every line you want in the heading (for example, sunset, syndicate, auto VI). The text editor supports bold, italic, and links.
  • Font size: Choose the size of the heading (for example, Extra large).
  • Highlight italic words: Select the words to highlight in the heading and press the italic (I) button. Those words are shown upright with the theme’s gradient.

Content and Badges

  • Small heading: Enter a short heading shown below the main heading (for example, Enter GTA VI Chaos).
  • Hero description: Add the description for the slide. The text editor supports bold, italic, links, and bulleted or numbered lists.
  • Badges: Each slide has three badges. The badge shows when it has text.
    • Badge icon: Select or upload an icon to display beside the badge text.
    • Badge text: Enter the text for the badge (for example, 19 Nov 2026, Playstation, or Xbox Series X/S).

Buttons

Each slide can show two buttons, and both have the same settings.

  • Button label: Enter the text shown on the button (for example, Pre Order Now or Explore More Games).
  • Button link: Select the page, product, or collection that the button opens.
  • Open in new tab: Turn this option on to open the button link in a new browser tab.
  • Button style: Choose the button style, such as Gradient or Secondary.
  • Show cart icon: Turn this option on to show a cart icon on the button.
  • Show arrow icon: Turn this option on to show an arrow icon on the button.

Tab

  • Tab heading: Enter the heading shown on the slide’s tab card (for example, Enter GTA VI Chaos).
  • Tab description: Enter a short description for the tab card. Keep it short for the best result.
