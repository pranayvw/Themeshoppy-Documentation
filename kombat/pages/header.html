Header section

The Header is the first point of contact for your customers, making it essential for creating a lasting impression and reinforcing your brand identity. With Kombat, you have full control over your header's layout and design, offering various options that seamlessly integrate with your store’s aesthetic.

The header includes elegantly designed icons for easy access to the cart, customer account, and search functionalities. To elevate your store’s navigation, Kombat offers separate guides for configuring the Announcement Bar, Dropdown Menu, and Mega Menu, ensuring a streamlined experience for your customers.

Setup

Steps to Set Up the Header Section in Your Shopify Theme, Kombat

How to Configure the Header

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Theme Editor, select the Header section from the left sidebar.
  • Adjust the settings, blocks, and layout options according to your preferences.
  • Click Save to apply your changes.

Configuration

Follow these steps to configure your Header

  • Color scheme: Choose a color scheme to control the background and text colors of the header section. Click Edit scheme to customize the selected scheme.
  • Header border radius: Adjust the corner roundness of the header container using the slider (for example, 0px).
  • Logo:
    • Logo: Upload your store logo using the Select logo option.
    • Logo width: Adjust the size of the logo displayed in the header using the width slider (for example, 110px).
    • Enable sticky header: Turn this option on if you want the header to remain fixed at the top of the page while scrolling.
    • Sticky header behavior: Choose how the sticky header appears while scrolling (for example, Show when scrolling up, which reveals the header when the visitor scrolls back up the page).
    • Logo position: Choose the layout positioning of the logo and navigation menu: Logo left or Logo center.
  • Header options:
    • Enable overlay: Enable this option to display the header on top of the hero banner (Only applies on the homepage).
  • Menu:
    • Select menu: Choose the main navigation menu that will appear in the header (for example, Main menu).
    • Account icon image: Upload a custom image to replace the default account icon in the header.
  • Header padding: Controls the spacing above and below the header.
    • Top spacing: Adjust the spacing above the header (for example, 20).
    • Bottom spacing: Adjust the spacing below the header (for example, 20).
  • Edge shadows: Softly blend the top and bottom edges of the header into the sections around it. Pick the color scheme used by the section above or below the header.
    • Show top shadow: Turn this option on to display a soft shadow along the top edge of the header.
    • Top shadow color scheme: Select the color scheme used by the section above the header so the shadow blends smoothly. Click Edit scheme to customize it.
    • Top shadow height: Set the height of the top shadow (for example, 16px).
    • Show bottom shadow: Turn this option on to display a soft shadow along the bottom edge of the header.
    • Bottom shadow color scheme: Select the color scheme used by the section below the header so the shadow blends smoothly. Click Edit scheme to customize it.
    • Bottom shadow height: Set the height of the bottom shadow (for example, 16px).
  • Theme Settings: Access global theme settings related to the header section.
  • Custom CSS: Add custom CSS code to apply custom styling to the header section.
