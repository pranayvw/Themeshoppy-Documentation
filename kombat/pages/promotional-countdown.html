Theme documentation

Promotional countdown

The Promotional countdown section in the Kombat theme shows a row of promotion cards above a centered heading, description, countdown timer, and button. Use it to promote a sale or a limited-time offer, with each card linking to a collection or page.

Configure promotional countdown Try the theme

Setup

Steps to Set Up the Promotional Countdown in Kombat

How to Configure the Promotional Countdown

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Kombat theme.
  • In the Template list, click Add section and select Promotional countdown, or select the section if it is already on the page.
  • Adjust the section settings according to your preferences.
  • Click Add Promotion card to add a card, then set its image, title, and link.
  • Click Save to apply your changes.

Promotional Countdown Section Settings

  • Color scheme: Choose a color scheme for the section. Use Edit scheme to customize the selected scheme.
  • Image ratio: Choose the shape of the card images (for example, Adapt to image). Adapt to image uses the first card’s image.
  • Heading:
    • Heading: Enter the section heading (for example, Level Up Your Setup Before Time Runs Out). The text editor supports bold, italic, and links.
    • Highlight italic words: Select the words to highlight in the heading and press the italic (I) button. Those words are shown upright with the theme’s gradient.
    • Heading font size: Choose the size of the heading (for example, Small).
    • Heading alignment: Align the heading to the left, center, or right.
    • Description: Add supporting text below the heading. The text editor supports bold, italic, links, and bulleted or numbered lists.
    • Description width: Set the width of the description using the slider (for example, 420px).
  • Button:
    • Button label: Enter the text shown on the button (for example, Explore Gaming Deals).
    • Button link: Select the page, product, or collection that the button opens (for example, Deals).
    • Button style: Choose the button style: Primary or Secondary.
    • Show cart icon: Turn this option on to show a cart icon on the button.
    • Show arrow icon: Turn this option on to show an arrow icon on the button.
  • Countdown:
    • End date: Enter the date the countdown ends, using the YYYY-MM-DD format (for example, 2026-12-31). Leave it blank to hide the countdown.
    • Days label: Enter the label shown under the days (for example, Days).
    • Hours label: Enter the label shown under the hours (for example, Hrs).
    • Minutes label: Enter the label shown under the minutes (for example, Mins).
    • Seconds label: Enter the label shown under the seconds (for example, Secs).
  • Edge shadows: Softly blend the top and bottom edges into the sections around this one. Pick the color scheme used by the section above or below.
    • Show top shadow: Turn this option on to display a shadow along the top edge.
    • Show bottom shadow: Turn this option on to display a shadow along the bottom edge.
  • Desktop spacing:
    • Padding top: Adjust the top spacing on desktop screens (for example, 100px).
    • Padding bottom: Adjust the bottom spacing on desktop screens (for example, 60px).
  • Mobile spacing:
    • Padding top: Adjust the top spacing on mobile screens (for example, 30px).
    • Padding bottom: Adjust the bottom spacing on mobile screens (for example, 40px).

Blocks

Promotion Card Block Settings

Each Promotion card block is one card in the row. Add as many cards as you need with Add Promotion card.

  • Image: Select or upload the image shown on the card.
  • Title: Enter a title for the card (for example, Promotion). It is not shown on the card and is used by screen readers.
  • Link: Select the page, product, or collection that the card opens (for example, Gaming Controllers).
