Newsletter

The Newsletter section in the falcon theme lets visitors subscribe to your email updates. Add a background image, customize the heading and description, and choose the button label and style to match your store.

Configure Newsletter Try the theme

Setup

Steps to Set Up the Newsletter Section in Falcon

How to Configure the Newsletter Section

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Falcon theme.
  • In the Theme Editor, locate the Footer group and click Add section.
  • Select Newsletter, or select the section if it is already added to the page.
  • Customize the background, heading, description, form button, and spacing settings.
  • Click Save to apply your changes.

Newsletter Section Settings

  • Color scheme: Choose a color scheme for the section. Use Edit scheme to customize the selected scheme.
  • Background image: Select or upload the image displayed behind the newsletter content.
  • Fixed background image: Turn this option on to keep the background image fixed as visitors scroll through the page.
  • Overlay color: Select a color to place over the background image. Leave this setting empty to use the section background color.
  • Overlay opacity: Adjust the opacity of the overlay (for example, 20%).
  • Height:
    • Section height: Choose the height of the newsletter section on desktop screens (for example, Medium). Select Adapt to image to adjust the section height based on the background image, or choose Small, Medium, or Large to set a predefined height.
    • Section height on mobile: Choose the height of the newsletter section on mobile screens (for example, Medium). Select Adapt to image to adjust the section height based on the background image, or choose Small, Medium, or Large to set a predefined height.
  • Heading:
    • Heading: Enter the main heading for the newsletter section (for example, Stay Ahead With Exclusive Gaming News Today). The text editor supports bold, italic, and links.
    • Highlight italic words: Turn this option on to display italicized words in the heading with the theme's gradient styling.
    • Heading font size: Choose the size of the newsletter heading. Available options include Extra large, Large, Medium, Small, and Extra small.
    • Heading alignment: Align the heading to the left, center, or right.
    • Description: Add supporting text below the heading. The text editor supports formatted text and links.
  • Form:
    • Button label: Enter the text displayed on the newsletter submit button (for example, Submit).
    • Button style: Choose the button style: Primary or Secondary.
  • Edge shadows: Softly blend the top and bottom edges into the sections around this one. Pick the color scheme used by the section above or below.
    • Show top shadow: Turn this option on to display a shadow along the top edge.
    • Top shadow color scheme: Select the color scheme for the top shadow.
    • Top shadow height: Adjust the height of the top shadow (for example, 180px).
    • Show bottom shadow: Turn this option on to display a shadow along the bottom edge.
    • Bottom shadow color scheme: Select the color scheme for the bottom shadow.
    • Bottom shadow height: Adjust the height of the bottom shadow.
  • Desktop padding:
    • Padding top: Adjust the top spacing on desktop screens (for example, 40px).
    • Padding bottom: Adjust the bottom spacing on desktop screens (for example, 40px).
  • Mobile padding:
    • Padding top: Adjust the top spacing on mobile screens (for example, 40px).
    • Padding bottom: Adjust the bottom spacing on mobile screens (for example, 40px).
