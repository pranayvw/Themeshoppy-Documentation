Footer section

The Footer is an important part of your store layout as it appears on every page and provides customers with quick access to essential information and navigation links. With the Aspire theme, the footer is designed to be flexible and visually organized, allowing you to display menus, policies, newsletter signup, and important store details in a structured layout.

The footer helps improve the user experience by making it easier for customers to find information such as policies, contact details, and additional navigation links. It also supports branding elements like logos and social media icons, helping you maintain a consistent brand identity across your store.

Steps to Set Up the Footer Section in Your Shopify Theme, Aspire

Steps

  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Aspire theme.
  • In the Theme Editor, scroll down and select the Footer section from the left sidebar.
  • Adjust the settings, blocks, and layout options according to your preferences.
  • Click Save to apply your changes.

Follow these steps to configure your Footer section

  • Color Scheme: Choose a color scheme to control the background and text colors of the footer section.
  • Show Logo: Enable or disable displaying the store logo in the footer.
  • Logo: Upload an image to display as your store logo in the footer.
  • Logo Width: Adjust the width of the footer logo in pixels (for example, 100px).
  • Image Gallery:
    • Show Image Gallery: Enable or disable displaying up to 4 image cards in the footer layout.
    • Image: Upload images for individual items in the gallery.
    • Title: Enter a title for each image item (for example: NECKLACE, 18k Gold Plated Ring).
    • Link: Add a URL link to make each gallery image clickable.
  • Newsletter:
    • Show Newsletter: Toggle on/off to display or hide the newsletter subscription section.
    • Heading: Enter a heading for the newsletter section (for example: UNLOCK EXCLUSIVE SPARKLE AND STYLE).
    • Text: Add a descriptive message encouraging visitors to subscribe to your newsletter.
    • Input Placeholder: Customize placeholder text inside the email input field (for example: Enter your email address).
  • Follow on Shop: Allow customers to follow your store through the Shop app. (Shop Pay must be enabled).
  • Social:
    • Show Social Icons: Enable to display social media profile icons linked to your store's social media accounts.
  • Localization:
    • Show Country/Region Selector: Enable or disable the country/region selector dropdown in the footer.
    • Show Language Selector: Enable or disable the language selector dropdown in the footer.
  • Payment Icons:
    • Show Payment Icons: Display accepted payment method logos at the bottom of the footer.
  • Bottom Banner:
    • Show Bottom Banner: Enable or disable displaying a full-width banner at the bottom of the footer.
    • Color Scheme: Select a color scheme specifically for the bottom banner area.
    • Banner Image: Upload a background or promotional image for the bottom banner.
    • Overlay Logo: Upload a brand logo overlay image to appear over the bottom banner.
    • Overlay Logo Width: Set the width of the overlay logo in pixels (for example: 1000px).
    • Overlay Text: Add custom rich text to display on top of the bottom banner.
    • Banner Height: Adjust the vertical height percentage of the banner (for example: 50%).
    • Overlay Custom Width: Set the width percentage for the text overlay container (for example: 50%).
  • Desktop Padding:
    • Padding Top: Adjust the top spacing on desktop screens (in px).
    • Padding Bottom: Adjust the bottom spacing on desktop screens (in px).
  • Mobile Padding:
    • Padding Top: Adjust the top spacing on mobile screens (in px).
    • Padding Bottom: Adjust the bottom spacing on mobile screens (in px).

Available Blocks in Footer

  • Information Block: The Information block allows you to display custom text content, brand messaging, and social media profile icons in the footer layout.
    Information Block Configuration
    • Heading: Enter a title for the information block (leave empty if not needed).
    • Content: Add rich text description or detailed content about your store.
    • Show Social Icons Below Content: Enable this toggle switch to display social media profile icons below the content text.
    • Width: Adjust the column width percentage of the Information block using the slider (for example, 30%).


  • Menu Block: The Menu block allows you to display navigation links in the footer layout. You can add multiple menu blocks to organize different link categories such as CATEGORIES, QUICK LINKS, POLICIES, or IMPORTED PRODUCTS.
    Menu Block Configuration
    • Heading: Enter a title for the menu block (for example: CATEGORIES, QUICK LINKS, or POLICIES).
    • Select Menu: Choose a navigation menu created in your Shopify admin menu list (Online Store → Navigation).
    • Width: Adjust the column width percentage of the menu block using the slider (for example, 17%).


  • Text Block: The Text block allows you to display custom text content in the footer, such as store introduction, contact details, business hours, or brand messaging.
    Text Block Configuration
    • Heading: Enter a title for the text block (for example: About us).
    • Text: Add rich text content using formatting options such as bold, italic, links, bulleted lists, and numbered lists.
    • Width: Adjust the column width percentage of the text block using the slider (for example, 25%).


FAQs

How do I add or edit links in the footer menus?

You can manage footer links by editing the navigation menus in your Shopify admin. Go to Online Store → Navigation, create or edit a menu, and assign it to the appropriate footer block inside the Theme Editor.

How can I add social media icons to the footer?

To display social media icons, go to Theme Settings → Social Media and add your social profile links. Then enable the Show Social Icons option in the Footer section settings.
