Theme documentation

Newsletter popup

The Newsletter popup in the Ranked theme shows a subscription popup to your visitors. It combines a heading and text, an email signup form, social media icons, and an image or video, and it can be set to appear only at the right moment.

Configure newsletter popup Try the theme

Setup

Steps to Set Up the Newsletter Popup in Ranked

How to Configure the Newsletter Popup

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Ranked theme.
  • In the Theme Editor, scroll to the bottom of the left panel and select Newsletter popup.
  • Turn on Show popup and adjust the settings according to your preferences.
  • Click Save to apply your changes.

Newsletter Popup Settings

  • Show popup: Turn this option on to display the newsletter popup.
  • Color scheme: Choose a color scheme for the popup. Use Edit scheme to customize the selected scheme.
  • Invert colors: Swaps the background and text colors of the color scheme on the content card.
  • Corner radius: Adjust the corner radius of the popup using the slider (for example, 24px).
  • Content:
    • Heading: Enter the popup heading (for example, Subscribe to our newsletter). The text editor supports bold, italic, and links.
    • Heading font size: Choose the size of the newsletter heading. Available options include Extra large, Large, Medium, Small, and Extra small.
    • Text: Add supporting text below the heading (for example, Sign up to receive updates, access to exclusive deals, and more.). The text editor supports bold, italic, links, and bulleted or numbered lists.
  • Signup:
    • Show email signup: Turn this option on to show the email signup form. Turn it off to show a button link instead.
    • Button label: Enter the text shown on the button (for example, Subscribe).
    • Button style: Choose the visual style of the Add to cart button. Available options include Primary, Secondary, and Gradient.
    • Show consent checkbox: Turn this option on to show a consent checkbox in the form.
  • Social media:
    • Show social media icons: Turn this option on to show your social media icons. Add your links in Theme settings → Social media.
    • Label: Enter the text shown beside the icons (for example, Follow us).
  • Media:
    • Show media: Turn this option on to show an image or video in the popup.
    • Image: Select or upload the image shown in the popup.
    • Video: Select a video to show in the popup. It is shown instead of the image.
    • Media position on desktop: Choose whether the media is placed on the Left or Right on desktop.
    • Media overlay opacity: Adjust the strength of the overlay over the media using the slider (for example, 0%).
  • Behavior:
    • Delay before showing: Set how many seconds to wait before the popup appears (for example, 5s).
    • Show only on home page: Turn this option on to show the popup only on the home page.
    • Hide for logged-in customers: Turn this option on to hide the popup for customers who are logged in.
    • Show once per visitor: Turn this option on to show the popup only once to each visitor.
