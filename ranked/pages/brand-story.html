Theme documentation

Brand story

The Brand story section in the ranked theme tells your story with a large heading and description, a row of showcase images, and highlight cards that present key facts about your store, such as the number of happy gamers or games available.

Configure brand story Try the theme

Setup

Steps to Set Up the Brand Story in Ranked

How to Configure the Brand Story

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Ranked theme.
  • In the Template list, click Add section and select Brand story, or select the section if it is already on the page.
  • Adjust the section settings according to your preferences.
  • Click Add block to add a Showcase image or a Highlight, then configure it.
  • Click Save to apply your changes.

Brand Story Section Settings

  • Color scheme: Choose a color scheme for the section. Use Edit scheme to customize the selected scheme.
  • Heading:
    • Heading: Enter the section heading (for example, ABOUT US). The text editor supports bold, italic, and links.
    • Highlight italic words: Select the words to highlight in the heading and press the italic (I) button. Those words are shown upright with the theme’s gradient.
    • Heading font size: Choose the size of the heading (for example, Largest).
    • Heading alignment: Align the heading to the left, center, or right.
    • Description: Add supporting text below the heading. The text editor supports bold, italic, links, and bulleted or numbered lists.
    • Description width: Set the width of the description using the slider (for example, 600px).
  • Highlights:
    • Card shade: Darkens the highlight cards from the section’s color scheme. Adjust it using the slider (for example, 30%).
  • Edge shadows: Softly blend the top and bottom edges into the sections around this one. Pick the color scheme used by the section above or below.
    • Show top shadow: Turn this option on to display a shadow along the top edge.
    • Top shadow color scheme: Select the color scheme for the top shadow.
    • Top shadow height: Adjust the height of the top shadow (for example, 180px).
    • Show bottom shadow: Turn this option on to display a shadow along the bottom edge.
    • Bottom shadow color scheme: Select the color scheme for the bottom shadow.
    • Bottom shadow height: Adjust the height of the bottom shadow (for example, 120px).
  • Desktop spacing:
    • Padding top: Adjust the top spacing on desktop screens (for example, 80px).
    • Padding bottom: Adjust the bottom spacing on desktop screens (for example, 80px).
  • Mobile spacing:
    • Padding top: Adjust the top spacing on mobile screens (for example, 48px).
    • Padding bottom: Adjust the bottom spacing on mobile screens (for example, 48px).

Blocks

Showcase Image Block Settings

Each Showcase image block is one image in the row next to the heading. Add as many images as you need with Add block.

  • Image: Select or upload the image shown in the row.
  • Link: Select the page, product, or collection that the image opens (for example, Jadebound: The Monkey King).

Blocks

Highlight Block Settings

Each Highlight block is one card below the heading. Add as many cards as you need with Add block.

  • Title: Enter the title of the card (for example, 5,00+ Games Available).
  • Description: Enter the text shown on the card.
  • Link: Paste a link or search for a page that the card opens.
  • Card width: Set the width of the card using the slider (for example, 32%).
  • Feature this card: Turn this option on to feature this card.
