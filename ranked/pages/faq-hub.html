Theme documentation

FAQ hub

The FAQ hub section in the ranked theme organizes your frequently asked questions into tabs. Each tab is a topic, such as shipping or payments, and shows its questions as an accordion that visitors can open and close, under a heading and description on a background image.

Configure FAQ hub Try the theme

Setup

Steps to Set Up the FAQ Hub in Ranked

How to Configure the FAQ Hub

Steps
  • From your Shopify admin, go to Online Store → Themes.
  • Click Customize on the Ranked theme.
  • In the Template list, click Add section and select FAQ hub, or select the section if it is already on the page.
  • Adjust the section settings according to your preferences.
  • Click Add block under FAQ hub and select FAQ tab, then enter the Tab label.
  • Click Add block under the FAQ tab and select FAQ item, then enter the Question and the Answer. Repeat for every question in the tab.
  • Click Save to apply your changes.

FAQ Hub Section Settings

  • Color scheme: Choose a color scheme for the section. Use Edit scheme to customize the selected scheme.
  • Background image: Select or upload the image shown behind the section.
  • Heading:
    • Heading: Enter the section heading (for example, Gaming FAQs Hub). The text editor supports bold, italic, and links.
    • Highlight italic words: Select the words to highlight in the heading and press the italic (I) button. Those words are shown upright with the theme’s gradient.
    • Heading font size: Choose the font size for the section heading. Available options include Extra large, Large, Medium, Small, and Extra small.
    • Heading alignment: Align the heading to the left, center, or right.
    • Description: Add supporting text below the heading. The text editor supports bold, italic, links, and bulleted or numbered lists.
    • Description width: Set the width of the description using the slider (for example, 640px).
  • Edge shadows: Softly blend the top and bottom edges into the sections around this one. Pick the color scheme used by the section above or below.
    • Show top shadow: Turn this option on to display a shadow along the top edge.
    • Top shadow color scheme: Select the color scheme for the top shadow.
    • Top shadow height: Adjust the height of the top shadow (for example, 180px).
    • Show bottom shadow: Turn this option on to display a shadow along the bottom edge.
    • Bottom shadow color scheme: Select the color scheme for the bottom shadow.
    • Bottom shadow height: Adjust the height of the bottom shadow (for example, 120px).
  • Desktop padding:
    • Padding top: Adjust the top spacing on desktop screens (for example, 70px).
    • Padding bottom: Adjust the bottom spacing on desktop screens (for example, 60px).
  • Mobile padding:
    • Padding top: Adjust the top spacing on mobile screens (for example, 40px).
    • Padding bottom: Adjust the bottom spacing on mobile screens (for example, 40px).

Blocks

FAQ Tab Block Settings

Each FAQ tab block is one topic. It appears as a tab above the questions, and it holds the FAQ item blocks of that topic. Add as many tabs as you need with Add block under FAQ hub.

  • Tab label: Enter the name of the tab (for example, Orders & Shipping).

Blocks

FAQ Item Block Settings

Each FAQ item block is one question and its answer, shown as an accordion item in its tab. Add them with Add block under an FAQ tab.

  • Question: Enter the question (for example, How long does shipping usually take?).
  • Answer: Enter the answer. The text editor supports bold, italic, links, and bulleted or numbered lists.
  • Open by default: Turn this option on to show the answer open when the tab is displayed.

Questions

Frequently asked questions

Select the FAQ hub section in the Theme Editor, click Add block, and select FAQ tab. Then enter the Tab label of the new block.

Click Add block under the FAQ tab and select FAQ item. Then enter the Question and the Answer. Questions appear in the order of the blocks.

Turn on Open by default in the FAQ item block of that question.

Select a different image in Background image in the section settings.
